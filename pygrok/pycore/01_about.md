### Bắt đầu ngay – Bài 1: Chuẩn bị môi trường + Hello World

#### 1\. Cài đặt Python (rất quan trọng)

  * Tải Python **3.12** hoặc **3.11** tại: <https://www.python.org/downloads/>
  * **Windows** : Khi cài nhớ **tick** vào ô **“Add Python to PATH”**
  * Kiểm tra đã cài thành công:



Bash
    
    
    python --version
    # hoặc
    python3 --version

#### 2\. Chọn công cụ viết code (khuyến nghị)

  * **Người mới** : VS Code + extension Python (Microsoft)
  * **Hoặc** : PyCharm Community (miễn phí)
  * **Hoặc** : Jupyter Notebook (rất tốt để học)



#### 3\. Viết chương trình đầu tiên

Mở terminal hoặc file hello.py và gõ:

Python
    
    
    print("Xin chào, tôi đang học Python!")
    print("Python version:", __import__("sys").version)

Chạy bằng lệnh:

Bash
    
    
    python hello.py

### Bài tập ngay hôm nay (bắt buộc làm)

  1. Cài đặt Python thành công và chụp màn hình kết quả python --version
  2. Viết chương trình in ra:
     * Tên của bạn
     * Tuổi
     * Lý do bạn muốn học Python
  3. Thử dùng input() để nhập tên từ bàn phím rồi in ra chào hỏi.



**Ví dụ:**

Python
    
    
    ten = input("Nhập tên của bạn: ")
    print(f"Xin chào {ten}! Chào mừng bạn đến với hành trình Python.")
