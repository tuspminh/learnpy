**Bài 3: Câu lệnh điều kiện (if – elif – else)**

Đây là bài cực kỳ quan trọng. Hầu như mọi chương trình thực tế đều dùng điều kiện để quyết định hành động.

* * *

### 1\. Cấu trúc cơ bản

Python
    
    
    if điều_kiện:
        # khối lệnh chạy nếu điều_kiện đúng (True)
        ...
    elif điều_kiện_khác:
        # chạy nếu điều_kiện trên sai, nhưng điều_kiện_khác đúng
        ...
    else:
        # chạy nếu tất cả điều kiện trên đều sai
        ...

**Lưu ý quan trọng:**

  * Phải có dấu hai chấm : ở cuối dòng if, elif, else
  * Khối lệnh bên trong phải **thụt lề** (thường dùng 4 dấu cách)
  * Python rất nghiêm về thụt lề



* * *

### 2\. Ví dụ cơ bản

Python
    
    
    tuoi = 18
    
    if tuoi >= 18:
        print("Bạn đã đủ tuổi trưởng thành")
    else:
        print("Bạn chưa đủ 18 tuổi")

* * *

### 3\. Nhiều điều kiện với elif

Python
    
    
    diem = 7.5
    
    if diem >= 8.0:
        print("Học lực: Giỏi")
    elif diem >= 6.5:
        print("Học lực: Khá")
    elif diem >= 5.0:
        print("Học lực: Trung bình")
    else:
        print("Học lực: Yếu")

Python sẽ kiểm tra từ trên xuống dưới. Gặp điều kiện đúng đầu tiên thì chạy khối đó và **bỏ qua** các phần còn lại.

* * *

### 4\. Kết hợp toán tử logic

Python
    
    
    tuoi = 20
    co_bang_lai = True
    
    if tuoi >= 18 and co_bang_lai:
        print("Được phép lái xe")
    else:
        print("Không được phép lái xe")

Python
    
    
    # Toán tử or
    ngay = "Chủ nhật"
    
    if ngay == "Thứ bảy" or ngay == "Chủ nhật":
        print("Cuối tuần!")
    else:
        print("Ngày thường")

Python
    
    
    # Toán tử not
    dang_mua = False
    
    if not dang_mua:
        print("Trời không mưa, đi chơi thôi!")

* * *

### 5\. if lồng nhau (Nested if)

Python
    
    
    diem = 8.5
    hanh_kiem = "Tốt"
    
    if diem >= 8.0:
        if hanh_kiem == "Tốt":
            print("Được khen thưởng")
        else:
            print("Điểm cao nhưng hạnh kiểm chưa tốt")
    else:
        print("Chưa đủ điều kiện khen thưởng")

Nên hạn chế lồng quá sâu (thường ≤ 2–3 tầng) để code dễ đọc.

* * *

### 6\. Một số mẹo hay dùng

Python
    
    
    # Gán giá trị theo điều kiện (ternary)
    tuoi = 20
    trang_thai = "Người lớn" if tuoi >= 18 else "Trẻ em"
    print(trang_thai)
    
    # Kiểm tra giá trị nằm trong khoảng
    diem = 7
    if 5 <= diem <= 10:          # rất Pythonic
        print("Điểm hợp lệ")

* * *

### 7\. Các lỗi thường gặp

Lỗi| Nguyên nhân| Cách tránh  
---|---|---  
IndentationError| Thụt lề sai| Luôn dùng 4 space, không trộn tab  
Quên dấu :| Cú pháp| Nhớ thêm : sau if/elif/else  
Dùng = thay vì ==| So sánh sai| = là gán, == là so sánh  
Viết else if| Sai cú pháp| Phải viết elif

### Bài tập Bài 3

**Bài 1:** Viết chương trình nhập một số nguyên, kiểm tra số đó là **chẵn** hay **lẻ**.

**Bài 2:** Viết chương trình nhập điểm trung bình (thang 10), in ra xếp loại:

  * > = 8.0 → Giỏi

  * > = 6.5 → Khá

  * > = 5.0 → Trung bình

  * < 5.0 → Yếu



**Bài 3:** Viết chương trình nhập năm sinh, tính tuổi hiện tại (năm 2026), rồi in ra:

  * Dưới 18 tuổi → “Vị thành niên”
  * Từ 18 đến 60 → “Người trưởng thành”
  * Trên 60 → “Người cao tuổi”



**Bài 4 (nâng cao):** Viết chương trình giải phương trình bậc nhất: ax + b = 0

  * Nhập a và b từ bàn phím
  * Xử lý các trường hợp: a = 0, b = 0, vô số nghiệm, vô nghiệm, có nghiệm duy nhất.
