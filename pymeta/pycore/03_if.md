1. Cú pháp - Indent là luật

Python không dùng {} như ngôn ngữ khác. Nó dùng thụt lề 4 dấu cách. Thụt sai là chết.
Python

tuoi = int(input("Nhập tuổi: "))

if tuoi < 13:
    print("Bạn là thiếu nhi")
    print("Chưa được dùng Facebook") # 2 dòng này cùng khối if
elif tuoi < 18:
    print("Bạn là teen")
else:
    print("Bạn đã trưởng thành")

print("Dòng này luôn chạy vì nó hết thụt lề")

Thứ tự: if -> có thể có nhiều elif -> có thể có 1 else. Chỉ 1 nhánh được chạy.

3. Viết gọn kiểu Pro

a) Ternary Operator - if 1 dòng:
Python

# Thay vì
if tong >= 300000:
    ship = 0
else:
    ship = 30000

# Viết gọn
ship = 0 if tong >= 300000 else 30000
