Mình chia lộ trình Python thành 7 Level. Mỗi level mình sẽ dạy theo công thức: Hiểu bản chất -> Code mẫu chuẩn -> Bài tập + Mini Project.

Đây là bản đồ toàn cảnh trước:

### LỘ TRÌNH 7 LEVEL - TỪ ZERO TỚI LÀM ĐƯỢC SẢN PHẨM

LEVEL 0: Tư duy lập trình & Setup chuẩn Dev

  * Cài đặt Python, VS Code, Git đúng cách
  * Cách chạy code, terminal, venv là gì, tại sao phải dùng
  * Tư duy biến, bộ nhớ, thuật toán cơ bản
  * _Project: Viết chương trình tính BMI đầu tiên_



LEVEL 1: Nền tảng Python Core - Phải thuộc như bảng cửu chương

  * Biến, kiểu dữ liệu: `int, float, str, bool, None`
  * Toán tử, nhập/xuất, ép kiểu
  * Câu lệnh điều kiện `if-elif-else` và logic
  * Vòng lặp `for, while`, `break, continue`
  * _Project: Game đoán số, máy tính bỏ túi_



LEVEL 2: Cấu trúc dữ liệu - Sức mạnh thật sự của Python

  * List, Tuple, Set, Dict - khi nào dùng cái nào?
  * String slicing, comprehension (vũ khí bí mật)
  * Xử lý dữ liệu lồng nhau
  * _Project: Quản lý danh bạ / Kho hàng bằng Dict_



LEVEL 3: Hàm & Tư duy Modular

  * Viết hàm sạch, `*args, **kwargs`, scope, lambda
  * Module, package, import chuẩn
  * Đệ quy, docstring, type hint
  * _Project: Bộ công cụ xử lý văn bản riêng của bạn_



LEVEL 4: Lập trình Hướng Đối Tượng (OOP) & Xử lý lỗi

  * Class, object, `**init**`, kế thừa, đa hình
  * `try-except`, file I/O, `with open`
  * _Project: Hệ thống quản lý sinh viên / bank account có lưu file_



LEVEL 5: Tư duy Dev Chuyên Nghiệp

  * `pip`, `venv`, `requirements.txt`
  * Git cơ bản, viết code theo PEP8
  * Testing với `pytest`, logging, debug
  * Thư viện hay dùng: `datetime, collections, pathlib, re`
  * _Project: Tool tự động đổi tên và sắp xếp 1000 file trong máy_



LEVEL 6: Chọn nhánh chuyên sâu (bạn muốn đi đâu?)

  1. Backend Web: FastAPI + Database
  2. Data / Automation: Pandas, NumPy, Selenium
  3. AI / LLM: Dùng API, xây bot, RAG cơ bản
