# Rust String Deep Dive — Buổi 4

## UTF-8, Byte, Unicode Scalar Value, `char` và String

Đây là một trong những buổi **quan trọng nhất của String trong Rust**.

Sau buổi này, bạn phải hiểu được tại sao:

```rust
let s = "Hello";
```

có thể truy cập theo byte, tại sao:

```rust
s.len()
```

không phải số ký tự, và tại sao:

```rust
s[0]
```

lại bị Rust từ chối.

---

# 1. Rust String là UTF-8

Trong Rust:

```rust
String
```

và:

```rust
str
```

lưu trữ text dưới dạng:

> **UTF-8 encoded bytes**

Đây là nguyên tắc nền tảng.

Ví dụ:

```rust
let a = "Hello";
let b = "Xin chào";
let c = "你好";
let d = "🚀";
```

Tất cả đều là UTF-8.

Mental model:

```text
String / str
      │
      ▼
UTF-8 bytes
```

Không phải:

```text
String
  ↓
array of char
```

Đây là khác biệt cực kỳ quan trọng.

---

# 2. Unicode và UTF-8 không phải một thứ

Trước tiên phải phân biệt:

```text
Unicode
UTF-8
```

### Unicode

Là hệ thống định nghĩa các ký tự và code point.

Ví dụ:

```text
A
é
你
🚀
```

đều có Unicode code point.

### UTF-8

Là một **encoding** dùng để biểu diễn Unicode thành bytes.

Ví dụ:

```text
Unicode character
       ↓
     UTF-8
       ↓
     bytes
```

Do đó:

```text
Unicode ≠ UTF-8
```

---

# 3. Byte là gì?

Một byte = 8 bits.

Rust có:

```rust
u8
```

để biểu diễn một byte.

Ví dụ:

```rust
let byte: u8 = 65;
```

Giá trị:

```text
65
```

có thể biểu diễn ký tự ASCII:

```text
A
```

---

# 4. ASCII là subset của UTF-8

ASCII chỉ có các ký tự cơ bản:

```text
A-Z
a-z
0-9
! @ # $
...
```

Các ký tự ASCII trong UTF-8 đều chiếm:

```text
1 byte
```

Ví dụ:

```rust
let s = "Hello";
```

UTF-8:

```text
H → 1 byte
e → 1 byte
l → 1 byte
l → 1 byte
o → 1 byte
```

Tổng:

```text
5 bytes
```

Do đó:

```rust
assert_eq!("Hello".len(), 5);
```

---

# 5. Nhưng Unicode không phải lúc nào cũng 1 byte

Ví dụ:

```rust
let s = "é";
```

`é` không phải ASCII.

UTF-8 của nó chiếm:

```text
2 bytes
```

Do đó:

```rust
fn main() {
    let s = "é";

    println!("{}", s.len());
}
```

Kết quả:

```text
2
```

Không phải:

```text
1
```

Đây là điểm đầu tiên cần ghi nhớ:

> `str::len()` trả về **số byte**, không phải số ký tự.

# 6. Ví dụ tiếng Việt

```rust
fn main() {
    let s = "Xin chào";

    println!("len = {}", s.len());
}
```

Bạn nhìn thấy:

```text
Xin chào
```

Có:

```text
8 ký tự
```

nếu tính cả khoảng trắng:

```text
X i n _ c h à o
```

Nhưng UTF-8 bytes nhiều hơn.

Đặc biệt:

```text
X → 1
i → 1
n → 1
space → 1
c → 1
h → 1
à → nhiều byte
o → 1
```

Vì vậy:

```rust
s.len()
```

không phải số ký tự hiển thị.

# 7. `len()` thực sự có nghĩa gì?

Với:

```rust
let s = "Hello";
```

```rust
s.len()
```

nghĩa là:

> Có bao nhiêu **bytes** trong string slice.

Không phải:

```text
characters
```

Không phải:

```text
Unicode code points
```

Không phải:

```text
grapheme clusters
```

Mà là:

```text
UTF-8 bytes
```

# 9. `.bytes()` với Unicode

# 10. `char` trong Rust là gì?

Rust có:

```rust
char
```

Một `char` đại diện cho:

> **Unicode Scalar Value**

Ví dụ:

```rust
let a: char = 'A';
let b: char = 'é';
let c: char = '你';
let d: char = '🚀';
```

Lưu ý:

```rust
'A'
```

là `char`.

Trong khi:

```rust
"A"
```

là `&str`.

Đây là hai type hoàn toàn khác nhau.

---

# 11. `'A'` vs `"A"`

```rust
let a = 'A';
let b = "A";
```

Type:

```text
'A'
 ↓
char

"A"
 ↓
&str
```

Mental model:

```text
'A'
 ↓
Unicode Scalar Value

"A"
 ↓
UTF-8 string slice
```

# 12. `char` có kích thước cố định

Rust `char` có kích thước:

```text
4 bytes
```

hay:

```text
32 bits
```

Ví dụ:

```rust
use std::mem::size_of;

fn main() {
    println!("{}", size_of::<char>());
}
```

Kết quả:

```text
4
```

Điều này khác với UTF-8 string.

Một Unicode character có thể chiếm:

```text
1 → 4 bytes
```

trong UTF-8.

Nhưng Rust `char` luôn có kích thước:

```text
4 bytes
```

---

# 13. UTF-8 encoding có độ dài từ 1 đến 4 bytes

Một Unicode scalar value trong UTF-8 có thể chiếm:

```text
1 byte
2 bytes
3 bytes
4 bytes
```

Ví dụ:

```text
ASCII        → 1 byte
é            → 2 bytes
你            → 3 bytes
🚀           → 4 bytes
```

Mental model:

```text
Unicode scalar value
          │
          ▼
        UTF-8
          │
    ┌─────┼─────┬─────┐
    ▼     ▼     ▼     ▼
   1B    2B    3B    4B
```

Nhưng:

```rust
println!("{}", "A".chars().count());
```

đều:


```text

```

# 15. Vì sao Rust không cho `s[0]`?

Đây là câu hỏi kinh điển.

Bạn có thể nghĩ:

```rust
let s = "Hello";
println!("{}", s[0]);
```

Nhưng Rust không cho.

Tại sao?

Bởi vì nếu:

```rust
s = "Hello"
```

thì:

```text
byte 0 = H
```

có vẻ đơn giản.

Nhưng:

```rust
s = "你好"
```

thì:

```text
byte 0
```

chỉ là **một phần của ký tự UTF-8**, không phải một `char`.

Rust không muốn định nghĩa một phép indexing mơ hồ.

# 21. `char` không đồng nghĩa với "ký tự người dùng nhìn thấy"

Đây là một level sâu hơn.

Ví dụ:

```text
é
```

có thể được biểu diễn bằng:

```text
U+00E9
```

hoặc:

```text
e + combining acute accent
```

Hai cách có thể nhìn gần như giống nhau.

Nhưng về Unicode scalar values, chúng khác nhau.

Đây là lý do:

```rust
s.chars().count()
```

cũng **không phải lúc nào là số ký tự mà người dùng nhìn thấy**.

---

# 22. Grapheme cluster

Ví dụ:

```text
é
```

có thể là một grapheme cluster.

Một grapheme cluster là khái niệm gần với:

> "một ký tự mà người dùng cảm nhận/nhìn thấy".

Rust standard library không cung cấp trực tiếp API đầy đủ để phân tích grapheme clusters.

Nếu cần xử lý Unicode text ở mức người dùng, thường cần crate Unicode chuyên dụng.

Nhưng hiện tại chỉ cần nhớ:

```text
bytes
   ↓
UTF-8 bytes

chars
   ↓
Unicode scalar values

graphemes
   ↓
user-perceived characters
```

Đây là **ba tầng khác nhau**.

---

# 23. Ba tầng cần thuộc

```text
"é"
 │
 ├───────────────┐
 │               │
 ▼               ▼
bytes           chars
 │               │
2 bytes         1 char
 │               │
 ▼               ▼
UTF-8           Unicode
                scalar value
```

Và ở tầng cao hơn:

```text
grapheme cluster
```

có thể vẫn là:

```text
1 user-perceived character
```

# 24. String slicing

Ta có:

```rust
let s = "Hello";
let a = &s[0..2];
```

Kết quả:

```text
He
```

Tại sao?

ASCII:

```text
H → byte 0
e → byte 1
```

Nên:

```text
0..2
```

là boundary hợp lệ.

---

# 25. Nhưng Unicode thì phải cẩn thận

Ví dụ:

```rust
let s = "é";
```

`é` có 2 bytes.

Ta có thể:

```rust
let a = &s[0..2];
```

Hợp lệ.

Nhưng:

```rust
let a = &s[0..1];
```

sẽ panic runtime.

Tại sao?

Vì byte 1 nằm giữa encoding của `é`.

Bạn đang tạo ra một `&str` không hợp lệ UTF-8.

Rust không cho phép điều đó.

---

# 26. Đây là một invariant cực kỳ quan trọng

Rust đảm bảo:

> Một `str` luôn chứa dữ liệu UTF-8 hợp lệ.

Do đó:

```rust
&str
```

không thể đại diện cho:

```text
một nửa UTF-8 character
```

Ví dụ:

```text
é
┌──────┐
│ B0 B1│
└──────┘
```

Không được tạo:

```text
┌────┐
│ B0 │
└────┘
```

thành một `&str`.

# 27. Character boundary

UTF-8 string có các boundary.

Ví dụ:

```text
"éabc"
```

Giả sử:

```text
é → 2 bytes
a → 1
b → 1
c → 1
```

Byte positions:

```text
0    2  3  4  5
│    │  │  │  │
é    a  b  c
```

Boundary hợp lệ:

```text
0
2
3
4
5
```

Không hợp lệ:

```text
1
```

Vì `1` nằm giữa UTF-8 encoding của `é`.

# 28. `is_char_boundary()`

Rust cung cấp:

```rust
s.is_char_boundary(index)
```

Ví dụ:

```rust
fn main() {
    let s = "éabc";

    println!("{}", s.is_char_boundary(0));
    println!("{}", s.is_char_boundary(1));
    println!("{}", s.is_char_boundary(2));
}
```

Khái niệm:

```text
0 → true
1 → false
2 → true
```

Đây là công cụ rất hữu ích khi làm việc với byte indexing.

# 29. `char_indices()`

Nếu muốn biết:

```text
character bắt đầu ở byte nào?
```

dùng:

```rust
let s = "aé你";

for (index, ch) in s.char_indices() {
    println!("{index}: {ch}");
}
```

Ta sẽ nhận được kiểu:

```text
0: a
1: é
3: 你
```

Vì:

```text
a → 1 byte
é → 2 bytes
你 → 3 bytes
```

Nên:

```text
a
  byte 0

é
  byte 1..3

你
  byte 3..6
```

# 30. Đây là cách hiểu rất quan trọng

Khi làm việc với Rust string:

```text
String / str
      │
      ▼
   UTF-8 bytes
      │
      ├── bytes()
      │
      ├── chars()
      │
      └── char_indices()
```

Không nên nghĩ:

```text
String
  ↓
array of characters
```

Hãy nghĩ:

```text
String
  ↓
UTF-8 byte sequence
```

# 31. Ví dụ deep dive

```rust
fn main() {
    let s = "Aé你🚀";

    println!("len = {}", s.len());
    println!("chars = {}", s.chars().count());
    println!("bytes = {}", s.bytes().count());

    for (index, ch) in s.char_indices() {
        println!("{index}: {ch}");
    }
}
```

Phân tích:

```text
A   → 1 byte
é   → 2 bytes
你  → 3 bytes
🚀 → 4 bytes
```

Tổng:

```text
1 + 2 + 3 + 4 = 10 bytes
```

Nhưng:

```text
4 Unicode scalar values
```

Do đó:

```text
s.len()              = 10
s.bytes().count()    = 10
s.chars().count()    = 4
```

Đây là một ví dụ bạn nên tự chạy bằng Rust.

```rust
Vec<u8>
```

> một vector các bytes.

# 34. Chuyển `Vec<u8>` thành `String`

Rust yêu cầu kiểm tra UTF-8:

```rust
let bytes = vec![82, 117, 115, 116];

let s = String::from_utf8(bytes).unwrap();

println!("{s}");
```

Output:

```text
Rust
```

`from_utf8()` kiểm tra:

```text
bytes
  ↓
UTF-8 hợp lệ?
  │
  ├── yes → String
  │
  └── no  → error
```

Đây là một invariant rất quan trọng.

# 35. `String::from_utf8_lossy`

Nếu bytes có thể không hợp lệ:

```rust
let bytes = vec![0xff, 0xfe];

let s = String::from_utf8_lossy(&bytes);

```

Rust có thể thay thế byte sequence không hợp lệ bằng replacement character:

```text
�
```

Nhưng đây là một chủ đề chúng ta sẽ đào sâu khi học xử lý binary/text.

# 36. ASCII và UTF-8

Một điều rất tiện:

```text
ASCII
  ⊂
UTF-8
```

Mọi ASCII byte đều là UTF-8 hợp lệ.

Ví dụ:

```text
A = 0x41
B = 0x42
C = 0x43
```

Do đó với text thuần ASCII:

```rust
s.len()
```

thường trùng với:

```rust
s.chars().count()
```

Nhưng chỉ là tình cờ.

Ví dụ:

```rust
"Hello".len() == 5
"Hello".chars().count() == 5
```

Trong khi:

```rust
"你好".len() != "你好".chars().count()
```

# 39. Sai lầm phổ biến #3

Đừng slice string bằng cách giả định mỗi ký tự là một byte:

```rust
&s[0..10]
```

Nếu string có Unicode, `10` có thể nằm giữa một UTF-8 character.

Cách an toàn hơn tùy mục đích:

```rust
s.chars().take(10)
```

hoặc sử dụng các API Unicode phù hợp.

# 41. Mental model cuối buổi

Hãy thuộc sơ đồ này:

```text
                Rust String / str
                       │
                       ▼
                 UTF-8 bytes
                       │
          ┌────────────┼────────────┐
          │            │            │
          ▼            ▼            ▼
       bytes()      chars()   char_indices()
          │            │            │
          ▼            ▼            ▼
       u8 bytes       char      byte index
                                  + char
```

Và:

```text
UTF-8
│
├── ASCII character → 1 byte
├── Unicode scalar  → 1–4 bytes
└── String length   → number of bytes
```

# Bài tập Buổi 4

## Bài 1 — `len()`

Không chạy chương trình, hãy dự đoán:

```rust
fn main() {
    println!("{}", "Hello".len());
    println!("{}", "é".len());
    println!("{}", "你".len());
    println!("{}", "🚀".len());
}
```

---

## Bài 2 — `chars()`

Dự đoán:

```rust
fn main() {
    println!("{}", "Hello".chars().count());
    println!("{}", "é".chars().count());
    println!("{}", "你".chars().count());
    println!("{}", "🚀".chars().count());
}
```

# Kiến thức phải thuộc sau Buổi 4

```text

      ↓
UTF-8 bytes
```

```text

```

```text

u8
```




```text
Bytes
```
