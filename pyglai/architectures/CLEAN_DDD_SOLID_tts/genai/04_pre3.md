    >  Bạn là lập trình viên python, thiét kế chi tiếp app sau theo kiến trúc clean, domain driven design và nguyên lý solid:
    app chuyển text thành voice, tiếng việt hoặc tiếng anh. đầu vào là file text hoặc folder chứa các file text.
    app cli dùng click để nhận tham số dòng lệnh. có các tham số sau : file/ folder, tts-engine, voice, rate, volume, pitch, merge (nếu có thì merge các file audio của các chunk của file text thành một file audio), chunk-size(mặc định 2000 ký tự, max 2500)
    xử lý file text, dùng underthesea với tiếng việt và spacy với tiếng anh, tách file text thành các chunk min 1500 ký tự, default 2000, max 2500), tách theo câu, cố gắng giữ ngữ cảnh.
    tts-engine: tuỳ chọn engine hệ thống, edge, google translate, google cloud tts.



Kiến trúc được thiết kế chi tiết theo các chuẩn **Clean Architecture**, **Domain-Driven Design (DDD)** và tuân thủ nguyên lý **SOLID**.

```python
    content: str
    language: Language

    source_path: Path
    language: Language
```

#### **Infrastructure Layer - Text Splitters**

Sử dụng nguyên lý **Single Responsibility** và **Open/Closed**: Mỗi ngôn ngữ có một strategy phân tách câu riêng.

`src/domain/services.py`

```python
import re
from typing import List
from src.domain.models import TextChunk, ChunkConfig, Language

class BaseTextSplitter:
    """Tách đoạn theo câu, đảm bảo kích thước tối đa và giữ nguyên ngữ cảnh."""

    def _split_sentences_to_chunks(self, sentences: List[str], config: ChunkConfig, language: Language) -> List[TextChunk]:
        chunks: List[TextChunk] = []
        current_sentences: List[str] = []
        current_len = 0
        chunk_idx = 0

        for sentence in sentences:
            sentence = sentence.strip()
            if not sentence:
                continue

            sentence_len = len(sentence)

            # Nếu 1 câu vượt quá max_size, cưỡng chế ngắt câu
            if sentence_len > config.max_size:
                if current_sentences:
                    chunks.append(TextChunk(chunk_idx, " ".join(current_sentences), language))
                    chunk_idx += 1
                    current_sentences, current_len = [], 0

                # Cắt nhỏ câu quá dài
                for sub in [sentence[i:i + config.default_size] for i in range(0, len(sentence), config.default_size)]:
                    chunks.append(TextChunk(chunk_idx, sub, language))
                    chunk_idx += 1
                continue

            # Kiểm tra xem thêm câu này vào có vượt max_size không
            if current_len + sentence_len + 1 > config.max_size:
                chunks.append(TextChunk(chunk_idx, " ".join(current_sentences), language))
                chunk_idx += 1
                current_sentences = [sentence]
                current_len = sentence_len
            else:
                current_sentences.append(sentence)
                current_len += sentence_len + 1

        if current_sentences:
            chunks.append(TextChunk(chunk_idx, " ".join(current_sentences), language))

        return chunks

```

```python
from typing import List
from underthesea import sent_tokenize
from src.domain.services import BaseTextSplitter
from src.domain.models import TextChunk, ChunkConfig, Language

class VietnameseTextSplitter(BaseTextSplitter):
    def split(self, text: str, config: ChunkConfig, language: Language = Language.VIETNAMESE) -> List[TextChunk]:
        sentences = sent_tokenize(text)
        return self._split_sentences_to_chunks(sentences, config, language)
```

`src/infrastructure/text_splitters/english.py`

```python
from typing import List
import spacy
from src.domain.services import BaseTextSplitter
from src.domain.models import TextChunk, ChunkConfig, Language

class EnglishTextSplitter(BaseTextSplitter):
    def __init__(self):
        self.nlp = spacy.load("en_core_web_sm", disable=["ner", "tagger", "lemmatizer"])

    def split(self, text: str, config: ChunkConfig, language: Language = Language.ENGLISH) -> List[TextChunk]:
        doc = self.nlp(text)
        sentences = [sent.text.strip() for sent in doc.sents]
        return self._split_sentences_to_chunks(sentences, config, language)
```

#### **Infrastructure Layer - TTS Engines**

Áp dụng **Factory Pattern** và **Dependency Inversion** để dễ dàng thêm các engine mới mà không thay đổi cốt lõi.

`src/infrastructure/tts_engines/edge_engine.py`

```python
import edge_tts
from pathlib import Path
from src.domain.models import TextChunk, AudioOptions
from src.domain.interfaces.tts_engine import ITTSEngine

class EdgeTTSEngine(ITTSEngine):
    async def synthesize(self, chunk: TextChunk, options: AudioOptions, output_path: Path) -> Path:
        voice = options.voice or ("vi-VN-HoaiMyNeural" if chunk.language.value == "vi" else "en-US-AriaNeural")
        rate_str = f"{int((options.rate - 1) * 100):+d}%"
        volume_str = f"{int((options.volume - 1) * 100):+d}%"
        pitch_str = f"{int(options.pitch):+d}Hz"

        communicate = edge_tts.Communicate(
            text=chunk.content,
            voice=voice,
            rate=rate_str,
            volume=volume_str,
            pitch=pitch_str
        )
        await communicate.save(str(output_path))
        return output_path

```

`src/infrastructure/tts_engines/factory.py`

```python
from src.domain.models import TTSEngineType
from src.domain.interfaces.tts_engine import ITTSEngine
from src.infrastructure.tts_engines.edge_engine import EdgeTTSEngine

class TTSEngineFactory:
    @staticmethod
    def create(engine_type: TTSEngineType) -> ITTSEngine:
        if engine_type == TTSEngineType.EDGE:
            return EdgeTTSEngine()
        # Khởi tạo các engine khác tương tự (SystemTTSEngine, GTTSEngine, GCPTTSEngine)
        raise NotImplementedError(f"Engine {engine_type} chưa được triển khai.")
```

```python
import asyncio
from pathlib import Path
from pydub import AudioSegment
from src.application.dtos import ConvertRequestDTO
from src.domain.models import ChunkConfig, AudioOptions, Language, TTSEngineType
from src.domain.interfaces.text_splitter import ITextSplitter
from src.infrastructure.tts_engines.factory import TTSEngineFactory

class ConvertTextToSpeechUseCase:
    def __init__(self, vi_splitter: ITextSplitter, en_splitter: ITextSplitter):
        self.vi_splitter = vi_splitter
        self.en_splitter = en_splitter

    async def execute(self, dto: ConvertRequestDTO) -> None:
        lang = Language(dto.language)
        splitter = self.vi_splitter if lang == Language.VIETNAMESE else self.en_splitter
        engine = TTSEngineFactory.create(TTSEngineType(dto.engine))
        config = ChunkConfig(default_size=dto.chunk_size, max_size=2500)
        options = AudioOptions(voice=dto.voice, rate=dto.rate, volume=dto.volume, pitch=dto.pitch)

        files = [dto.input_path] if dto.input_path.is_file() else list(dto.input_path.glob("*.txt"))

        for file in files:
            text = file.read_text(encoding="utf-8")
            chunks = splitter.split(text, config, lang)
            
            output_dir = file.parent / f"{file.stem}_audio"
            output_dir.mkdir(exist_ok=True)
            
            audio_files = []
            for chunk in chunks:
                out_file = output_dir / f"chunk_{chunk.index:04d}.mp3"
                await engine.synthesize(chunk, options, out_file)
                audio_files.append(out_file)

            if dto.merge and audio_files:
                combined = AudioSegment.empty()
                for af in audio_files:
                    combined += AudioSegment.from_file(af)
                combined.export(file.parent / f"{file.stem}_merged.mp3", format="mp3")

```

#### **Presentation Layer - CLI (Click)**

`src/presentation/cli.py`

```python
import asyncio
import click
from pathlib import Path
from src.application.dtos import ConvertRequestDTO
from src.application.use_cases import ConvertTextToSpeechUseCase
from src.infrastructure.text_splitters.vietnamese import VietnameseTextSplitter
from src.infrastructure.text_splitters.english import EnglishTextSplitter

@click.command()
@click.option("--input", "-i", "input_path", required=True, type=click.Path(exists=True, path_type=Path), help="Đường dẫn File hoặc Folder text")
@click.option("--lang", "-l", type=click.Choice(["vi", "en"]), default="vi", help="Ngôn ngữ xử lý")
@click.option("--tts-engine", type=click.Choice(["system", "edge", "gtts", "gcp"]), default="edge", help="TTS Engine")
@click.option("--voice", type=str, default=None, help="Tên voice mong muốn")
@click.option("--rate", type=float, default=1.0, help="Tốc độ đọc (1.0 = bình thường)")
@click.option("--volume", type=float, default=1.0, help="Âm lượng (1.0 = bình thường)")
@click.option("--pitch", type=float, default=0.0, help="Độ cao giọng đọc")
@click.option("--merge", is_flag=True, help="Merge toàn bộ chunk thành 1 file duy nhất")
@click.option("--chunk-size", type=click.IntRange(1500, 2500), default=2000, help="Độ dài tối đa mỗi chunk (1500-2500)")
def main(input_path: Path, lang: str, tts_engine: str, voice: str, rate: float, volume: float, pitch: float, merge: bool, chunk_size: int):
    dto = ConvertRequestDTO(
        input_path=input_path,
        language=lang,
        engine=tts_engine,
        voice=voice,
        rate=rate,
        volume=volume,
        pitch=pitch,
        merge=merge,
        chunk_size=chunk_size
    )

    use_case = ConvertTextToSpeechUseCase(
        vi_splitter=VietnameseTextSplitter(),
        en_splitter=EnglishTextSplitter()
    )

    asyncio.run(use_case.execute(dto))
    click.echo("Hoàn tất chuyển đổi Text thành Voice!")

if __name__ == "__main__":
    main()

```

### **3. Điểm nổi bật về thiết kế**

1. **Clean Architecture & DDD**:
* `Domain` độc lập hoàn toàn với thư viện bên ngoài (dùng `Protocol` để định nghĩa interface).
* `Application` chỉ phối hợp Use Case, không chứa logic chi tiết về cách đọc text hay gọi thư viện TTS.
* `Infrastructure` chứa các chi tiết kỹ thuật cụ thể (EdgeTTS, Underthesea, Spacy).


2. **Áp dụng Nguyên lý SOLID**:
* **Single Responsibility (SRP)**: Mỗi class làm đúng 1 nhiệm vụ (Splitting, Synthesizing, Handling CLI).
* **Open/Closed (OCP)**: Thêm TTS Engine mới chỉ cần tạo class mới triển khai `ITTSEngine` và khai báo vào `TTSEngineFactory` mà không sửa logic Use Case.
* **Liskov Substitution (LSP)** & **Interface Segregation (ISP)**: Các triển khai Splitter và TTS Engine tuân thủ tuyệt đối Contract đã tạo qua `Protocol`.
* **Dependency Inversion (DIP)**: `ConvertTextToSpeechUseCase` phụ thuộc vào `ITextSplitter` (Abstraction) chứ không phụ thuộc trực tiếp vào triển khai cụ thể của Spacy hay Underthesea.
