> Py draft
    bạn là lập trình viên python, thiét kế chi tiếp app sau theo kiến trúc clean, domain driven design và nguyên lý solid:
    app chuyển text thành voice, tiếng việt hoặc tiếng anh. đầu vào là file text hoặc folder chứa các file text.
    app cli dùng click để nhận tham số dòng lệnh. có các tham số sau : file/ folder, tts-engine, voice, rate, volume, pitch, --no-merge (mặc định thì merge các file audio của các chunk của file text thành một file audio, nếu có --no-merge thì không), chunk-size(mặc định 2000 ký tự, max 2500)
    output:  chunk audio lưu trong file-text-name/, merged-audio thì lưu chung thư mục với file text.
    xử lý file text, dùng underthesea với tiếng việt và spacy với tiếng anh, tách file text thành các chunk min 1500 ký tự, default 2000, max 2500), tách theo câu, cố gắng giữ ngữ cảnh.
    tts-engine: tuỳ chọn engine hệ thống, edge, google translate, google cloud tts.
    python 3.15 với uv



Kiến trúc chi tiết cho dự án **Text-to-Speech CLI** (tên dự án gợi ý: `py-tts-draft`) áp dụng chuẩn **Clean Architecture**, **Domain-Driven Design (DDD)** và các nguyên lý **SOLID**, chạy trên **Python 3.15** với **uv**.

```python
from enum import Enum, auto
from pathlib import Path

class Language(Enum):
    VIETNAMESE = "vi"
    ENGLISH = "en"

class TTSEngineType(Enum):

    EDGE = "edge"
    GTRANSLATE = "gtranslate"

@dataclass(frozen=True)

    rate: float = 1.0
    volume: float = 1.0
    pitch: float = 0.0
    voice: str | None = None

@dataclass(frozen=True)
class TextChunk:
    index: int
    text: str
    language: Language

@dataclass(frozen=True)
class ProcessTarget:
    file_path: Path
    language: Language

```

#### `src/domain/interfaces.py`

```python
from abc import ABC, abstractmethod
from pathlib import Path
from src.domain.models import TextChunk, AudioOptions, TTSEngineType

class TextSegmenterInterface(ABC):
    @abstractmethod
    def split_into_sentences(self, text: str) -> list[str]:
        pass

class TTSEngineInterface(ABC):
    @abstractmethod
    async def synthesize(self, chunk: TextChunk, options: AudioOptions, output_path: Path) -> Path:
        pass

class AudioMergerInterface(ABC):
    @abstractmethod
    def merge(self, audio_paths: list[Path], output_path: Path) -> Path:
        pass

```

#### `src/domain/services.py`

Thực thi thuật toán gom câu thành các chunk vừa đảm bảo ngữ cảnh vừa nằm trong khoảng `[1500, max_chunk_size]`.

```python
from src.domain.interfaces import TextSegmenterInterface
from src.domain.models import TextChunk, Language

class TextChunkerDomainService:
    MIN_SIZE = 1500

    def __init__(self, segmenter: TextSegmenterInterface, max_size: int = 2500, target_size: int = 2000):
        if not (self.MIN_SIZE <= target_size <= max_size <= 2500):
            raise ValueError("Size không hợp lệ: MIN(1500) <= Target <= Max <= 2500")
        self.segmenter = segmenter
        self.max_size = max_size
        self.target_size = target_size

    def chunk_text(self, text: str, language: Language) -> list[TextChunk]:
        sentences = self.segmenter.split_into_sentences(text)
        chunks: list[TextChunk] = []
        current_sentences: list[str] = []
        current_len = 0
        idx = 0

        for sent in sentences:
            sent_len = len(sent)
            if current_len + sent_len > self.max_size and current_len >= self.MIN_SIZE:
                chunks.append(TextChunk(index=idx, text=" ".join(current_sentences), language=language))
                idx += 1
                current_sentences = [sent]
                current_len = sent_len
            else:
                current_sentences.append(sent)
                current_len += sent_len

        if current_sentences:
            chunks.append(TextChunk(index=idx, text=" ".join(current_sentences), language=language))

        return chunks

```

### 2. Infrastructure Layer (`src/infrastructure/`)

Nơi cài đặt cụ thể các Adapter cho công cụ phân tách câu và TTS Engine.

#### `src/infrastructure/segmenters/vietnamese.py`

```python
from underthesea import sent_tokenize
from src.domain.interfaces import TextSegmenterInterface

class VietnameseSegmenter(TextSegmenterInterface):
    def split_into_sentences(self, text: str) -> list[str]:
        return sent_tokenize(text)

```

#### `src/infrastructure/segmenters/english.py`

```python
import spacy
from src.domain.interfaces import TextSegmenterInterface

class EnglishSegmenter(TextSegmenterInterface):
    def __init__(self):
        self.nlp = spacy.load("en_core_web_sm", disable=["ner", "parser", "lemmatizer"])
        self.nlp.add_pipe("sentencizer")

    def split_into_sentences(self, text: str) -> list[str]:
        doc = self.nlp(text)
        return [sent.text.strip() for sent in doc.sents]

```

#### Factory chọn Segmenter theo ngôn ngữ

```python
from src.domain.models import Language
from src.domain.interfaces import TextSegmenterInterface
from src.infrastructure.segmenters.vietnamese import VietnameseSegmenter
from src.infrastructure.segmenters.english import EnglishSegmenter

class SegmenterFactory:
    @staticmethod
    def get_segmenter(language: Language) -> TextSegmenterInterface:
        match language:
            case Language.VIETNAMESE:
                return VietnameseSegmenter()
            case Language.ENGLISH:
                return EnglishSegmenter()

```

### 3. Application Layer (`src/application/`)

Điều phối dòng chảy dữ liệu giữa Domain và Infrastructure.

#### `src/application/dtos.py`

```python
from src.domain.models import TTSEngineType, Language

@dataclass
class ConversionConfigDTO:
    input_path: Path
    language: Language
    engine_type: TTSEngineType
    voice: str | None
    rate: float
    volume: float
    pitch: float
    no_merge: bool
    chunk_size: int

```

#### `src/application/use_cases.py`

```python
from pathlib import Path
from src.application.dtos import ConversionConfigDTO
from src.domain.models import AudioOptions, TextChunk
from src.domain.services import TextChunkerDomainService
from src.domain.interfaces import TTSEngineInterface, AudioMergerInterface
from src.infrastructure.segmenters.factory import SegmenterFactory

class ConvertTextToSpeechUseCase:
    def __init__(self, tts_engine: TTSEngineInterface, merger: AudioMergerInterface):
        self.tts_engine = tts_engine
        self.merger = merger

    async def execute(self, config: ConversionConfigDTO) -> None:
        target_files = [config.input_path] if config.input_path.is_file() else list(config.input_path.glob("*.txt"))
        options = AudioOptions(rate=config.rate, volume=config.volume, pitch=config.pitch, voice=config.voice)

        for file_path in target_files:
            await self._process_single_file(file_path, config, options)

    async def _process_single_file(self, file_path: Path, config: ConversionConfigDTO, options: AudioOptions) -> None:
        text = file_path.read_text(encoding="utf-8")
        
        # 1. Chunking
        segmenter = SegmenterFactory.get_segmenter(config.language)
        chunker = TextChunkerDomainService(segmenter=segmenter, target_size=config.chunk_size)
        chunks = chunker.chunk_text(text, config.language)

        # 2. Chuẩn bị thư mục chứa Chunk Audio
        chunk_dir = file_path.parent / file_path.stem
        chunk_dir.mkdir(parents=True, exist_ok=True)

        # 3. Synthesize từng Chunk
        generated_audio_paths: list[Path] = []
        for chunk in chunks:
            chunk_audio_path = chunk_dir / f"chunk_{chunk.index:04d}.mp3"
            await self.tts_engine.synthesize(chunk, options, chunk_audio_path)
            generated_audio_paths.append(chunk_audio_path)

        # 4. Merge file nếu không bật --no-merge
        if not config.no_merge and generated_audio_paths:
            merged_output_path = file_path.parent / f"{file_path.stem}.mp3"
            self.merger.merge(generated_audio_paths, merged_output_path)

```

### 4. Presentation Layer (`src/presentation/cli.py`)

Cung cấp giao diện CLI sử dụng **Click**.

```python
import asyncio
from pathlib import Path
import click

from src.application.dtos import ConversionConfigDTO
from src.application.use_cases import ConvertTextToSpeechUseCase
from src.domain.models import TTSEngineType, Language
from src.infrastructure.tts.factory import TTSEngineFactory
from src.infrastructure.audio.merger import PyDubAudioMerger

@click.command()
@click.argument("input_path", type=click.Path(exists=True, path_type=Path))
@click.option("--lang", type=click.Choice(["vi", "en"]), default="vi", help="Ngôn ngữ bản gốc")
@click.option("--tts-engine", type=click.Choice(["system", "edge", "gtranslate", "google_cloud"]), default="edge")
@click.option("--voice", default=None, help="Tên voice cụ thể")
@click.option("--rate", default=1.0, type=float, help="Tốc độ nói")
@click.option("--volume", default=1.0, type=float, help="Âm lượng")
@click.option("--pitch", default=0.0, type=float, help="Cao độ")
@click.option("--no-merge", is_flag=True, default=False, help="Không gom file audio chunk thành file duy nhất")
@click.option("--chunk-size", default=2000, type=click.IntRange(1500, 2500), help="Kích thước chunk (1500-2500)")
def main(input_path: Path, lang: str, tts_engine: str, voice: str | None, rate: float, volume: float, pitch: float, no_merge: bool, chunk_size: int):
    """Ứng dụng chuyển đổi Text/Folder chứa Text thành Voice Audio."""
    
    config = ConversionConfigDTO(
        input_path=input_path,
        language=Language(lang),
        engine_type=TTSEngineType(tts_engine),
        voice=voice,
        rate=rate,
        volume=volume,
        pitch=pitch,
        no_merge=no_merge,
        chunk_size=chunk_size
    )

    # Dependency Injection
    engine = TTSEngineFactory.create(config.engine_type)
    merger = PyDubAudioMerger()
    use_case = ConvertTextToSpeechUseCase(tts_engine=engine, merger=merger)

    asyncio.run(use_case.execute(config))

if __name__ == "__main__":
    main()

```

### Điểm nổi bật của Thiết kế

1. **Single Responsibility (S):** Mỗi class đảm nhận duy nhất 1 nhiệm vụ (ví dụ: `VietnameseSegmenter` chỉ tách câu tiếng Việt, `PyDubAudioMerger` chỉ gộp audio).
2. **Open/Closed (O):** Muốn thêm TTS Engine mới (ví dụ: ElevenLabs), chỉ cần viết thêm một class triển khai `TTSEngineInterface` mà không sửa bất kỳ code nào ở Application hay Domain layer.
3. **Liskov Substitution (L) & Interface Segregation (I):** Mọi TTS Engine đều tuân thủ contract của `TTSEngineInterface`, có thể thay thế cho nhau dễ dàng.
4. **Dependency Inversion (D):** Application Use Case chỉ phụ thuộc vào các Abstraction (Interfaces), các thư viện bên thứ 3 nằm hoàn toàn ở Infrastructure.
