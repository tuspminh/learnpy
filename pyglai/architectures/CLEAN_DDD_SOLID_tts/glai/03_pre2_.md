> Bạn là lập trình viên python, thiét kế chi tiếp app sau theo kiến trúc clean, domain driven design và nguyên lý solid:app chuyển text thành voice, tiếng việt hoặc tiếng anh. đầu vào là file text hoặc folder chứa các file text.app cli dùng click để nhận tham số dòng lệnh. có các tham số sau : file/ folder, tts-engine, voice, rate, volume, pitch, merge (nếu có thì merge các file audio của các chunk của file text thành một file audio), chunk-size(mặc định 2000 ký tự, max 2500)xử lý file text, dùng underthesea với tiếng việt và spacy với tiếng anh, tách file text thành các chunk min 1500 ký tự, default 2000, max 2500), tách theo câu, cố gắng giữ ngữ cảnh.tts-engine: tuỳ chọn engine hệ thống, edge, google translate, google cloud tts.


Chào bạn, dưới đây là thiết kế chi tiết cho ứng dụng Text-to-Speech (TTS) CLI được xây dựng bằng Python, áp dụng nghiêm ngặt kiến trúc Clean Architecture, Domain-Driven Design (DDD) và các nguyên lý SOLID.

* * *

## 🏢 Kiến trúc Tổng quan (Clean Architecture + DDD)

Hệ thống được chia thành 4 lớp độc lập, phụ thuộc từ ngoài vào trong:

  1. Domain Layer: Chứa nghiệp vụ cốt lõi (Chunking, Audio, TTS Interfaces). Không phụ thuộc thư viện ngoài.
  2. Use Cases Layer: Điều hướng luồng công việc (Xử lý file/folder, gọi chunking, gọi TTS, merge file).
  3. Infrastructure Layer: Cài đặt chi tiết kỹ thuật (NLP Spacy/Underthesea, Các Adapter cho Edge/Google TTS, File System).
  4. Presentation Layer: Giao diện dòng lệnh (CLI dùng thư viện `click`).

## 🛠️ Thiết kế Code Chi tiết & Áp dụng SOLID

## 1\. Domain Layer (`domain/`)

Đảm bảo nguyên lý Single Responsibility Principle (SRP) và là trung tâm của DDD.
    
    
    # domain/models.py
    from dataclasses import dataclass
    from typing import List, Optional
    
    @dataclass(frozen=True)
    class TTSConfig:
        engine_name: str
        voice: str
        rate: int
        volume: float
        pitch: Optional[float]
        chunk_size: int = 2000
    
    @dataclass
    class TextChunk:
        content: str
        language: str
        sequence_number: int
    
    @dataclass
    class AudioFile:
        file_path: str
    
    
    
    # domain/interfaces.py
    from abc import ABC, abstractmethod
    from typing import List
    from domain.models import TextChunk, TTSConfig, AudioFile
    
    class ISentenceSplitter(ABC):
        @abstractmethod
        def split_into_sentences(self, text: str) -> List[str]:
            """Tách văn bản thành danh sách các câu"""
            pass
    
    class ITTSEngine(ABC):
        @abstractmethod
        def synthesize(self, chunk: TextChunk, config: TTSConfig, output_path: str) -> AudioFile:
            """Chuyển text chunk thành file audio"""
            pass
    
    class IAudioMerger(ABC):
        @abstractmethod
        def merge(self, audio_files: List[AudioFile], output_path: str) -> AudioFile:
            """Gộp nhiều file audio thành một"""
            pass
    
    class IFileSystem(ABC):
        @abstractmethod
        def list_txt_files(self, path: str) -> List[str]: pass
        @abstractmethod
        def read_text(self, file_path: str) -> str: pass
        @abstractmethod
        def ensure_dir(self, path: str) -> None: pass
    

Áp dụng Domain Service để xử lý thuật toán tách chunk phức tạp nhằm giữ ngữ cảnh (Min 1500, Max 2500).
    
    
    # domain/services.py
    from typing import List
    from domain.models import TextChunk
    from domain.interfaces import ISentenceSplitter
    
    class TextSplitterService:
        def __init__(self, splitter: ISentenceSplitter, lang: str):
            self.splitter = splitter
            self.lang = lang
    
        def create_chunks(self, text: str, target_size: int = 2000) -> List[TextChunk]:
            sentences = self.splitter.split_into_sentences(text)
            chunks = []
            current_chunk = []
            current_length = 0
            seq = 0
    
            for sentence in sentences:
                sentence_len = len(sentence)
                # Ngưỡng tối đa là 2500 ký tự
                if current_length + sentence_len > 2500 and current_length >= 1500:
                    chunks.append(TextChunk(" ".join(current_chunk), self.lang, seq))
                    current_chunk = []
                    current_length = 0
                    seq += 1
                
                current_chunk.append(sentence)
                current_length += sentence_len
    
            if current_chunk:
                chunks.append(TextChunk(" ".join(current_chunk), self.lang, seq))
                
            return chunks
    

## 2\. Infrastructure Layer (`infrastructure/`)

Áp dụng Dependency Inversion Principle (DIP): Hiện thực hóa các interface từ Domain.
    
    
    # infrastructure/nlp/vi_splitter.py
    from domain.interfaces import ISentenceSplitter
    from underthesea import sent_tokenize
    
    class VietnameseSentenceSplitter(ISentenceSplitter):
        def split_into_sentences(self, text: str) -> list[str]:
            return sent_tokenize(text)
    
    # infrastructure/nlp/en_splitter.py
    from domain.interfaces import ISentenceSplitter
    import spacy
    
    class EnglishSentenceSplitter(ISentenceSplitter):
        def __init__(self):
            self.nlp = spacy.load("en_core_web_sm", disable=["ner", "textcat"])
            
        def split_into_sentences(self, text: str) -> list[str]:
            doc = self.nlp(text)
            return [sent.text for sent in doc.sents]
    

Cài đặt các dịch vụ TTS cụ thể (Open-Closed Principle - OCP: Muốn thêm Engine mới chỉ cần tạo file mới kế thừa `ITTSEngine`).
    
    
    # infrastructure/tts/edge_engine.py
    from domain.interfaces import ITTSEngine
    from domain.models import TextChunk, TTSConfig, AudioFile
    import edge_tts
    import asyncio
    
    class EdgeTTSEngine(ITTSEngine):
        def synthesize(self, chunk: TextChunk, config: TTSConfig, output_path: str) -> AudioFile:
            # Edge TTS yêu cầu chạy async, sử dụng chạy đồng bộ giả lập cho Clean Architecture
            async def _speak():
                communicate = edge_tts.Communicate(
                    text=chunk.content, 
                    voice=config.voice,
                    rate=f"{config.rate:+}%", # e.g. +10% hoặc -10%
                    volume=f"{config.volume:+}%"
                )
                await communicate.save(output_path)
                
            asyncio.run(_speak())
            return AudioFile(output_path)
    

_(Tương tự triển khai cho`SystemEngine` bằng pyttsx3, `GttsEngine` bằng gTTS, và `GCloudEngine` bằng google-cloud-texttospeech)_.

## 3\. Use Cases Layer (`use_cases/`)

Nơi điều phối quy trình chạy app mà không quan tâm CLI hay giao diện Web đang kích hoạt nó.
    
    
    # use_cases/convert_text_to_speech.py
    import os
    from typing import List, Dict
    from domain.interfaces import ITTSEngine, IAudioMerger, IFileSystem, ISentenceSplitter
    from domain.services import TextSplitterService
    from domain.models import TTSConfig, AudioFile
    
    class ConvertTextToSpeechUseCase:
        def __init__(self, 
                     fs: IFileSystem, 
                     splitters: Dict[str, ISentenceSplitter], 
                     engines: Dict[str, ITTSEngine], 
                     merger: IAudioMerger):
            self.fs = fs
            self.splitters = splitters
            self.engines = engines
            self.merger = merger
    
        def execute(self, input_path: str, config: TTSConfig, merge_output: bool, lang: str) -> None:
            # 1. Thu thập danh sách file đầu vào
            files = []
            if os.path.isdir(input_path):
                files = self.fs.list_txt_files(input_path)
            else:
                files = [input_path]
    
            engine = self.engines.get(config.engine_name)
            splitter = self.splitters.get(lang)
            splitter_service = TextSplitterService(splitter, lang)
    
            for file_path in files:
                text = self.fs.read_text(file_path)
                # 2. Chia nhỏ văn bản theo ngữ cảnh câu
                chunks = splitter_service.create_chunks(text, config.chunk_size)
                
                generated_audio_files: List[AudioFile] = []
                base_name = os.path.splitext(file_path)[0]
                
                # 3. Tạo Audio cho từng chunk
                for chunk in chunks:
                    chunk_output = f"{base_name}_chunk_{chunk.sequence_number}.mp3"
                    audio = engine.synthesize(chunk, config, chunk_output)
                    generated_audio_files.append(audio)
                
                # 4. Gộp file nếu có yêu cầu tham số --merge
                if merge_output and len(generated_audio_files) > 1:
                    final_output = f"{base_name}_final.mp3"
                    self.merger.merge(generated_audio_files, final_output)
                    # Xóa các file chunk tạm sau khi gộp thành công
                    for f in generated_audio_files:
                        os.remove(f.file_path)
    

## 4\. Presentation Layer (`presentation/`) và `main.py`

Sử dụng thư viện `click` để định nghĩa CLI và thực hiện Dependency Injection (DI) thủ công tại `main.py`.
    
    
    # presentation/cli.py
    import click
    from use_cases.convert_text_to_speech import ConvertTextToSpeechUseCase
    from domain.models import TTSConfig
    
    def create_cli(use_case: ConvertTextToSpeechUseCase):
        @click.command()
        @click.argument('input-path', type=click.Path(exists=True))
        @click.option('--engine', 'tts_engine', default='edge', type=click.Choice(['system', 'edge', 'google-translate', 'google-cloud']))
        @click.option('--voice', default='vi-VN-HoaiAnNeural')
        @click.option('--rate', default=0, type=int, help="Tốc độ nói (thay đổi % hoặc giá trị thô tùy engine)")
        @click.option('--volume', default=100, type=float)
        @click.option('--pitch', default=0, type=float)
        @click.option('--chunk-size', default=2000, type=click.IntRange(1500, 2500))
        @click.option('--merge', is_flag=True, help="Gộp các chunk thành 1 file duy nhất")
        @click.option('--lang', default='vi', type=click.Choice(['vi', 'en']))
        def main_command(input_path, tts_engine, voice, rate, volume, pitch, chunk_size, merge, lang):
            """Ứng dụng CLI chuyển đổi văn bản (File/Thư mục) thành Giọng nói."""
            config = TTSConfig(
                engine_name=tts_engine, voice=voice, rate=rate, 
                volume=volume, pitch=pitch, chunk_size=chunk_size
            )
            click.echo(f"Đang xử lý dữ liệu từ: {input_path} với Engine: {tts_engine}...")
            use_case.execute(input_path, config, merge, lang)
            click.echo("🎉 Hoàn thành chuyển đổi!")
    
        return main_command
    
    
    
    # main.py (Composition Root - Nơi ráp nối toàn bộ hệ thống)
    from infrastructure.services.file_system import RealFileSystem
    from infrastructure.services.ffmpeg_merger import FfmpegAudioMerger
    from infrastructure.nlp.vi_splitter import VietnameseSentenceSplitter
    from infrastructure.nlp.en_splitter import EnglishSentenceSplitter
    from infrastructure.tts.edge_engine import EdgeTTSEngine
    # Import các engine khác tại đây...
    
    from use_cases.convert_text_to_speech import ConvertTextToSpeechUseCase
    from presentation.cli import create_cli
    
    if __name__ == '__main__':
        # Khởi tạo các chi tiết hạ tầng (Infrastructure)
        fs = RealFileSystem()
        merger = FfmpegAudioMerger()
        
        splitters = {
            "vi": VietnameseSentenceSplitter(),
            "en": EnglishSentenceSplitter()
        }
        
        engines = {
            "edge": EdgeTTSEngine(),
            # "system": SystemTTSEngine(), ...
        }
        
        # Inject vào Use Case (Nghiệp vụ ứng dụng)
        use_case = ConvertTextToSpeechUseCase(fs, splitters, engines, merger)
        
        # Chạy CLI ứng dụng
        cli = create_cli(use_case)
        cli()

## 💎 Cách hệ thống đáp ứng các nguyên lý thiết kế

  1. Single Responsibility (SRP): `TextSplitterService` chỉ lo thuật toán gom nhóm văn bản, `EdgeTTSEngine` chỉ lo giao tiếp API của Edge, `cli.py` chỉ lo bóc tách tham số dòng lệnh từ người dùng.
  2. Open-Closed (OCP): Khi bạn cần thêm một bộ thư viện NLP mới (ví dụ: `VnCoreNLP`), bạn chỉ cần tạo class mới hiện thực `ISentenceSplitter` và khai báo thêm ở `main.py` mà hoàn toàn không sửa đổi code cốt lõi trong `domain/` hay `use_cases/`.
  3. Liskov Substitution (LSP): Tất cả các Engine TTS (`EdgeTTSEngine`, `GcloudEngine`) đều tuân thủ chặt chẽ interface `ITTSEngine`. Việc thay thế qua lại giữa chúng thông qua CLI option không làm hỏng ứng dụng.
  4. Interface Segregation (ISP): Phân chia rõ ràng các Interface nhỏ gọn cho từng mục đích (`ISentenceSplitter`, `ITTSEngine`, `IAudioMerger`) thay vì gộp chung vào một Interface hạ tầng duy nhất.
  5. Dependency Inversion (DIP): Lớp `ConvertTextToSpeechUseCase` cao cấp không phụ thuộc trực tiếp vào SDK của Google hay thư viện Spacy. Nó giao tiếp thông qua các Interface trừu tượng được định nghĩa sẵn ở lớp Domain.



Để tiếp tục hoàn thiện mã nguồn, bạn có muốn tôi viết chi tiết phần code tích hợp cho Google Cloud TTS hay cấu hình chuyên sâu cho thư viện Pydub để xử lý gộp file không?
