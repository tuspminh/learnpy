Ngoài thư viện Pillow, Python còn có 3 thư viện rất mạnh mẽ khác để chuyển đổi ảnh thành file PDF, mỗi thư viện lại phù hợp với từng nhu cầu cụ thể:

## 1. Thư viện img2pdf (Khuyên dùng - Tốt nhất cho định dạng ảnh)

Đây là thư viện được viết riêng cho mục đích này. Nó không tái mã hóa (re-encode) lại ảnh mà chỉ đóng gói trực tiếp dữ liệu ảnh vào định dạng PDF.

* Ưu điểm: Tốc độ xử lý cực kỳ nhanh, giữ nguyên 100% chất lượng ảnh gốc và dung lượng file PDF tạo ra gần như bằng tổng dung lượng các file ảnh cộng lại (không bị phình to dung lượng).
* Cài đặt: pip install img2pdf
* Đoạn code mẫu:
```
import os
import img2pdf

folder_name = "sach_cat_may"
output_pdf = "Sach_img2pdf.pdf"

# Lấy danh sách ảnh và sắp xếp theo đúng thứ tự
image_files = [os.path.join(folder_name, f) for f in os.listdir(folder_name) if f.lower().endswith(('.jpg', '.jpeg', '.png'))]
image_files.sort()

# Đóng gói ảnh thành PDF
with open(output_pdf, "wb") as f:
    f.write(img2pdf.convert(image_files))

print("Đã xuất PDF thành công bằng img2pdf!")
```

## 2. Thư viện reportlab (Tốt nhất khi cần thiết kế layout, chèn chữ)

reportlab là một thư viện tạo PDF chuyên nghiệp và toàn diện nhất trong Python. Nó cho phép bạn tự định nghĩa kích thước trang giấy, căn lề, chèn số trang, tiêu đề hoặc viết chữ đè lên ảnh.

* Ưu điểm: Tùy biến rất cao, có thể tạo ra các trang sách PDF chuẩn chỉ có lề lối đẹp mắt.
* Cài đặt: pip install reportlab
* Đoạn code mẫu:
```
import os
from reportlab.lib.pagesizes import letter
from reportlab.pdfgen import canvas


folder_name = "sach_cat_may"
output_pdf = "Sach_ReportLab.pdf"

image_files = [f for f in os.listdir(folder_name) if f.lower().endswith(('.jpg', '.jpeg', '.png'))]
image_files.sort()

# Tạo một file canvas PDF mới
c = canvas.Canvas(output_pdf, pagesize=letter)
width, height = letter # Kích thước trang chuẩn (bạn có thể thay đổi tùy ý)

for file_name in image_files:
    img_path = os.path.join(folder_name, file_name)
    # Vẽ ảnh lên toàn bộ trang PDF
    c.drawImage(img_path, 0, 0, width, height)
    # Tạo trang mới cho bức ảnh tiếp theo
    c.showPage()

# Lưu file PDF lại
c.save()
print("Đã xuất PDF thành công bằng ReportLab!")
```

## 3. Thư viện PyMuPDF (hay còn gọi là fitz)

Đây là một thư viện xử lý PDF có tốc độ xử lý nhanh hàng đầu hiện nay trong hệ sinh thái Python. Nó thường được dùng để đọc, chỉnh sửa tài liệu PDF nhưng tính năng tạo PDF từ ảnh của nó cũng rất xuất sắc.

* Ưu điểm: Cực kỳ nhanh, cú pháp ngắn gọn và xử lý mượt mà với số lượng ảnh lớn lên đến hàng nghìn trang.
* Cài đặt: pip install pymupdf
* Đoạn code mẫu:

```
import osimport fitz  # PyMuPDF

folder_name = "sach_cat_may"
output_pdf = "Sach_PyMuPDF.pdf"

image_files = [f for f in os.listdir(folder_name) if f.lower().endswith(('.jpg', '.jpeg', '.png'))]
image_files.sort()

# Tạo một tài liệu PDF trốngdoc = fitz.open()
for file_name in image_files:
    img_path = os.path.join(folder_name, file_name)
    
    # Mở file ảnh như một tài liệu tạm thời
    img_doc = fitz.open(img_path)
    
    # Chuyển đổi ảnh thành định dạng PDF trong bộ nhớ
    pdf_bytes = img_doc.convert_to_pdf()
    img_pdf = fitz.open("pdf", pdf_bytes)
    
    # Chèn trang PDF vừa tạo từ ảnh vào file tài liệu chính
    doc.insert_pdf(img_pdf)
    img_doc.close()
    img_pdf.close()

# Lưu file PDF cuối cùng
doc.save(output_pdf)
doc.close()
print("Đã xuất PDF thành công bằng PyMuPDF!")
```

## Pillow

Để gộp toàn bộ các file ảnh đã tải thành một file PDF duy nhất, bạn cần sử dụng thư viện Pillow (thư viện xử lý ảnh phổ biến nhất trong Python).
Dưới đây là đoạn code mở rộng, tự động tìm các file ảnh trong thư mục theo đúng thứ tự sắp xếp và xuất ra file PDF:

## 1. Cài đặt thư viện Pillow

Trước khi chạy code, bạn cần cài đặt thư viện Pillow bằng lệnh sau trong Terminal/Command Prompt:

pip install Pillow

## 2. Đoạn code Python chuyển ảnh thành PDF

Bạn có thể tạo một file mới (ví dụ: convert_to_pdf.py) nằm cùng thư mục với đoạn code tải ảnh trước đó và chạy:

```
import osfrom PIL import Image
def images_to_pdf(image_folder, output_pdf_name):
    print("Đang quét và sắp xếp các file ảnh...")
    
    # Danh sách các đuôi định dạng ảnh hợp lệ
    valid_extensions = (".jpg", ".jpeg", ".png")
    
    # Lấy toàn bộ file trong thư mục ảnh, lọc các file không phải ảnh và sắp xếp theo tên
    image_files = [
        f for f in os.listdir(image_folder) 
        if f.lower().endswith(valid_extensions)
    ]
    
    # Sắp xếp danh sách file theo thứ tự bảng chữ cái/số (đảm bảo đúng số trang)
    image_files.sort()

    if not image_files:
        print(f"Lỗi: Không tìm thấy file ảnh nào trong thư mục '{image_folder}'!")
        return

    print(f"Tìm thấy {len(image_files)} ảnh. Bắt đầu chuyển đổi...")

    # Mở ảnh đầu tiên và chuyển sang hệ màu RGB (bắt buộc đối với định dạng PDF)
    first_image_path = os.path.join(image_folder, image_files[0])
    first_image = Image.open(first_image_path).convert('RGB')

    # Mở tất cả các ảnh còn lại và chuyển sang hệ màu RGB
    other_images = []
    for file_name in image_files[1:]:
        img_path = os.path.join(image_folder, file_name)
        img = Image.open(img_path).convert('RGB')
        other_images.append(img)

    # Lưu ảnh đầu tiên thành file PDF và đính kèm (append) tất cả các ảnh còn lại vào sau
    first_image.save(
        output_pdf_name, 
        save_all=True, 
        append_images=other_images
    )
    
    print(f"=== Xuất file PDF thành công: {output_pdf_name} ===")
if __name__ == "__main__":
    # Cấu hình thư mục chứa ảnh và tên file PDF muốn xuất ra
    FOLDER_NAME = "sach_cat_may"
    OUTPUT_PDF = "Sach_Thiet_Ke_Cat_May_Quynh_Huong.pdf"
    
    images_to_pdf(FOLDER_NAME, OUTPUT_PDF)
```

## Ưu điểm của đoạn code này:

* Đúng thứ tự: Hàm image_files.sort() kết hợp với cách đặt tên file có số 0 phía trước ở bước trước (ví dụ: trang_001.jpg, trang_002.jpg) giúp các trang sách không bị đảo lộn vị trí trong file PDF.
* Tối ưu dung lượng: Thư viện Pillow tự động nén ảnh thông minh khi đóng gói vào PDF để file không bị quá nặng mà vẫn giữ được độ nét ban đầu của ảnh SlideShare.
