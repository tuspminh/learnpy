# Sau khóa học bạn sẽ làm được

* Viết CSS thuần thành thạo, không phụ thuộc framework.
* Hiểu cách trình duyệt tính toán và áp dụng CSS (cascade, specificity, inheritance).
* Thiết kế giao diện responsive cho điện thoại, máy tính bảng và desktop.
* Sử dụng **Flexbox** và **CSS Grid** để xây dựng bố cục hiện đại.
* Tạo hiệu ứng chuyển động bằng **transition**, **transform** và **animation**.
* Áp dụng các phương pháp tổ chức mã như **BEM**, CSS Variables và component-based CSS.
* Xây dựng giao diện chuyên nghiệp cho các ứng dụng **Flask**, **Jinja2**, **FastAPI** và các dự án Python web.

## Phương pháp giảng dạy

Mỗi buổi học sẽ có cấu trúc cố định:

1. Lý thuyết nền tảng.
2. Minh họa bằng hình dung trực quan (ASCII khi phù hợp).
3. Giải thích chi tiết từng thuộc tính và cơ chế hoạt động.
4. Ví dụ nhỏ, dễ hiểu.
5. Ví dụ nâng cao.
6. Những lỗi phổ biến và cách khắc phục.
7. Best Practices trong dự án thực tế.
8. Bài tập thực hành.
9. Mini Project áp dụng kiến thức của buổi học.

Mỗi ví dụ sẽ là **một tệp HTML hoàn chỉnh có CSS đầy đủ**, để bạn chỉ cần lưu thành `.html` và mở bằng trình duyệt là có thể chạy ngay.

Lộ trình này sẽ giúp bạn học CSS một cách bài bản, đồng thời phục vụ trực tiếp cho việc phát triển ứng dụng web bằng Python. Trong **Buổi 1**, chúng ta sẽ bắt đầu từ cách trình duyệt tải HTML, phân tích CSS và render giao diện, làm rõ các khái niệm như **CSS Rule**, **Selector**, **Property**, **Value**, **Cascade**, cùng những ví dụ trực quan và hoàn chỉnh.
