# Khóa học HTML bài bản dành cho Python Developer

# Buổi 4: Liên kết (Hyperlink) với thẻ `<a>`

---

# Mục tiêu

Sau buổi học này, bạn sẽ:

* Hiểu hyperlink hoạt động như thế nào.
* Thành thạo thẻ `<a>`.
* Phân biệt đường dẫn tuyệt đối và tương đối.
* Biết tạo liên kết nội bộ, email, điện thoại, tải tệp.
* Hiểu cách tổ chức website nhiều trang.
* Biết cách Flask và Jinja2 tạo liên kết động.

---

# 1. Hyperlink là gì?

Điều làm nên World Wide Web chính là **Hyperlink**.

Ví dụ:

```
Trang chủ
    │
    ├── Giới thiệu
    ├── Sản phẩm
    ├── Tin tức
    └── Liên hệ
```

Khi người dùng bấm vào một liên kết, trình duyệt sẽ gửi một HTTP Request đến URL tương ứng.

Ví dụ:

```
Click

↓

https://example.com/about

↓

Browser Request

↓

Server

↓

HTML

↓

Render
```

---

# 2. Thẻ `<a>`

Cú pháp cơ bản:

```html
<a href="https://example.com">
    Truy cập Website
</a>
```

Kết quả:

```
Truy cập Website
```

Trong đó:

```
a

↓

Anchor
```

```
href

↓

Hypertext Reference

↓

Địa chỉ cần đến
```

---

# 3. Thuộc tính `href`

Đây là thuộc tính quan trọng nhất.

Ví dụ:

```html
<a href="https://google.com">
Google
</a>
```

Browser sẽ chuyển đến Google khi nhấp chuột.

---

# 4. Absolute URL (Đường dẫn tuyệt đối)

Ví dụ:

```html
<a href="https://python.org">
Python
</a>
```

hoặc

```html
<a href="https://flask.palletsprojects.com">
Flask
</a>
```

Đây là URL đầy đủ.

```
https://

↓

Tên miền

↓

Đường dẫn
```

Ví dụ:

```
https://example.com/news/python
```

---

# 5. Relative URL (Đường dẫn tương đối)

Giả sử website có cấu trúc:

```
website/

│

├── index.html

├── about.html

├── contact.html

└── news.html
```

Trong `index.html`

```html
<a href="about.html">
Giới thiệu
</a>
```

Không cần ghi:

```html
https://website.com/about.html
```

---

## Ví dụ

```html
<a href="contact.html">
Liên hệ
</a>
```

---

# 6. Di chuyển thư mục

Ví dụ:

```
website/

│

├── index.html

│

├── pages/

│      about.html

│

└── images/

        logo.png
```

Từ:

```
index.html
```

sang

```
about.html
```

```html
<a href="pages/about.html">
About
</a>
```

---

Ngược lại.

Trong

```
pages/about.html
```

muốn quay về

```
index.html
```

```html
<a href="../index.html">
Home
</a>
```

`..`

có nghĩa:

```
Lùi lên một thư mục
```

---

# 7. Anchor trong cùng trang

Có thể nhảy đến một vị trí cụ thể trong trang.

Ví dụ:

```html
<h2 id="python">
Python
</h2>
```

Liên kết:

```html
<a href="#python">
Đến phần Python
</a>
```

Browser sẽ cuộn đến phần có `id="python"`.

---

# 8. Mục lục

```html
<h2 id="html">HTML</h2>

<h2 id="css">CSS</h2>

...

<h2 id="js">JavaScript</h2>
```

Đây là cách tạo mục lục trong các tài liệu dài.

# 9. Mở tab mới

Thuộc tính:

```html
target="_blank"
```

Ví dụ:

```html
<a href="https://python.org"
   target="_blank">

Python

</a>
```

Kết quả:

```
Click

↓

Tab mới
```

---

## Bảo mật

Khi dùng:

```html
target="_blank"
```

nên thêm:

```html
rel="noopener noreferrer"
```

Ví dụ:

```html
<a href="https://python.org"
   target="_blank"
   rel="noopener noreferrer">

Python

</a>
```

Điều này giúp tăng tính bảo mật và hiệu năng.

# 16. Navigation chuẩn Semantic

Thay vì:

```html
<div>

<a href="index.html">Home</a>

<a href="about.html">About</a>

</div>
```

Nên dùng:

```html
<nav>

<ul>

<li><a href="index.html">Trang chủ</a></li>

<li><a href="about.html">Giới thiệu</a></li>

<li><a href="contact.html">Liên hệ</a></li>

</ul>

</nav>
```

Điều này giúp trình duyệt, công cụ tìm kiếm và trình đọc màn hình hiểu đây là khu vực điều hướng.

# 17. Liên kết trong Flask

Trong HTML thuần, bạn thường viết:

```html
<a href="about.html">

About

</a>
```

Nhưng trong Flask, **không nên** ghi cứng tên tệp.

Ví dụ:

```python
@app.route("/")
def home(): ...


@app.route("/about")
def about(): ...
```

Template Jinja2:

```html
<a href="{{ url_for('home') }}">
Trang chủ
</a>

<a href="{{ url_for('about') }}">
Giới thiệu
</a>
```

Nếu sau này đổi route từ:

```python
@app.route("/about")
```

thành:

```python
@app.route("/gioi-thieu")
```

bạn **không cần sửa template**, vì `url_for()` sẽ tự tạo URL phù hợp.

# 19. Những lỗi thường gặp

## ❌ Quên `href`

Sai:

```html
<a>Google</a>
```

Đúng:

```html
<a href="https://google.com">
Google
</a>
```

---

## ❌ Dùng `target="_blank"` nhưng thiếu `rel`

Sai:

```html
<a href="https://python.org"
target="_blank">

Python

</a>
```

Đúng:

```html
<a href="https://python.org"
target="_blank"
rel="noopener noreferrer">

Python

</a>
```

---

## ❌ Dùng đường dẫn tuyệt đối cho liên kết nội bộ

Không nên:

```html
<a href="https://mysite.com/about.html">
About
</a>
```

Nên:

```html
<a href="about.html">
About
</a>
```

---

## ❌ Không dùng `url_for()` trong Flask

Sai:

```html
<a href="/about">
```

Đúng:

```html
<a href="{{ url_for('about') }}">
```

Đây là thực hành tốt trong mọi dự án Flask.

# Tổng kết

Trong buổi học này, bạn đã nắm được:

* Cách sử dụng thẻ `<a>` và thuộc tính `href`.
* Phân biệt đường dẫn tuyệt đối và tương đối.
* Tạo liên kết nội bộ trong trang bằng `id`.
* Mở liên kết ở tab mới với `target="_blank"` và `rel="noopener noreferrer"`.
* Tạo liên kết email, điện thoại và tải tệp.
* Thiết kế thanh điều hướng theo chuẩn Semantic HTML.
* Sử dụng `url_for()` trong Flask để tạo liên kết động.

Ở **Buổi 5**, chúng ta sẽ học về **Hình ảnh (Images)** với thẻ `<img>`, bao gồm các thuộc tính `src`, `alt`, `title`, `width`, `height`, kỹ thuật ảnh responsive (`srcset`, `picture`), lazy loading và cách tối ưu hình ảnh cho hiệu năng và SEO.
