# Phương pháp học

Mỗi buổi sẽ gồm 6 phần:

1. **Lý thuyết**: Giải thích chi tiết từ bản chất.
2. **So sánh với Python**: Chỉ ra điểm giống và khác để tận dụng nền tảng Python của bạn.
3. **Ví dụ nhỏ**: Minh họa từng khái niệm.
4. **Ví dụ hoàn chỉnh**: Một chương trình áp dụng các kiến thức vừa học.
5. **Best Practices**: Cách viết mã theo tiêu chuẩn hiện đại.
6. **Bài tập thực hành**: Từ cơ bản đến nâng cao để tự luyện.

Trong suốt khóa học, mình sẽ thường xuyên so sánh JavaScript với Python để giúp bạn chuyển đổi tư duy nhanh hơn, đồng thời nhấn mạnh các điểm khác biệt dễ gây lỗi cho lập trình viên Python khi mới học JavaScript.

Ở **Buổi 1**, chúng ta sẽ bắt đầu với **JavaScript là gì, ECMAScript, JavaScript Engine, Runtime, Browser vs Node.js, cách JavaScript được thực thi**, trước khi viết chương trình đầu tiên. Đây là nền tảng quan trọng để hiểu toàn bộ ngôn ngữ về sau.
