# Giai đoạn 1 – Python Foundation

# Buổi 19. Exception (Xử lý ngoại lệ)

> **Exception** là một trong những kỹ năng quan trọng nhất của lập trình viên Python. Trong các dự án thực tế, chương trình không chỉ cần chạy đúng khi dữ liệu hợp lệ mà còn phải **xử lý được các tình huống bất thường** như nhập sai dữ liệu, không tìm thấy tệp, lỗi kết nối mạng, lỗi cơ sở dữ liệu,...

> Một chương trình chuyên nghiệp **không được phép "crash"** chỉ vì một lỗi nhỏ có thể dự đoán trước.

---

# Mục tiêu

Sau buổi học này, bạn sẽ:

* Hiểu Exception là gì.
* Phân biệt Syntax Error và Exception.
* Sử dụng `try`, `except`, `else`, `finally`.
* Bắt nhiều loại Exception.
* Sử dụng `raise`.
* Tạo Custom Exception.
* Biết cách ghi log lỗi.
* Áp dụng Best Practices trong xử lý ngoại lệ.

---

# 1. Exception là gì?

Exception là **ngoại lệ** xảy ra khi chương trình đang chạy (runtime).

Ví dụ:

```python
print(10 / 0)
```

Kết quả:

```text
ZeroDivisionError: division by zero
```

Chương trình dừng ngay lập tức.

---

# 2. Syntax Error và Exception

## Syntax Error

Sai cú pháp.

```python
if True
    print("Hello")
```

Kết quả:

```text
SyntaxError
```

Chương trình **không thể chạy**.

---

## Exception

Cú pháp đúng nhưng xảy ra lỗi khi chạy.

```python
number = int("abc")
```

Kết quả:

```text
ValueError
```

---

# 3. `try` và `except`

```python
try:
    number = int(input("Nhập số: "))
    print(number)
except ValueError:
    print("Bạn phải nhập số!")
```

Ví dụ:

```text
Nhập số: abc
Bạn phải nhập số!
```

Chương trình **không bị dừng**.

---

# 4. Nhiều câu lệnh trong `try`

```python
try:
    a = int(input("A: "))
    b = int(input("B: "))

    print(a / b)

except ValueError:
    print("Nhập sai kiểu dữ liệu.")

except ZeroDivisionError:
    print("Không thể chia cho 0.")
```

---

# 5. Một `except` bắt nhiều Exception

```python
try:
    a = int(input())
    b = int(input())

    print(a / b)

except ValueError, ZeroDivisionError:
    print("Có lỗi xảy ra.")
```

---

# 6. Bắt mọi Exception

```python
try:
    print(10 / 0)

except Exception as error:
    print(error)
```

Kết quả:

```text
division by zero
```

`error` là đối tượng Exception.

---

# 7. Xem kiểu Exception

```python
try:
    int("abc")

except Exception as error:
    print(type(error))
```

Kết quả:

```text
<class 'ValueError'>
```

---

# 8. `else`

`else` chỉ chạy nếu **không có Exception**.

```python
try:
    result = 10 / 2

except ZeroDivisionError:
    print("Lỗi.")

else:
    print(result)
```

Kết quả:

```text
5.0
```

---

# 9. `finally`

`finally` luôn được thực thi.

```python
try:
    print(10 / 2)

finally:
    print("Đóng chương trình")
```

Kết quả:

```text
5.0
Đóng chương trình
```

Ngay cả khi có Exception:

```python
try:
    print(10 / 0)

finally:
    print("Cleanup")
```

Kết quả:

```text
Cleanup
ZeroDivisionError
```

---

# 10. Ví dụ mở tệp

```python
try:
    file = open("data.txt")

    print(file.read())

finally:
    file.close()
```

Nếu `open()` thành công, `file.close()` luôn được gọi.

> Tuy nhiên, trong Python hiện đại, nên dùng `with open(...)` thay vì tự quản lý `close()`. Chúng ta sẽ học `with` ở giai đoạn Intermediate.

---

# 11. `raise`

Tự tạo Exception.

```python
age = -5

if age < 0:
    raise ValueError("Tuổi không hợp lệ")
```

Kết quả:

```text
ValueError: Tuổi không hợp lệ
```

---

# 12. Kiểm tra dữ liệu

```python
def set_age(age):
    if age < 0:
        raise ValueError("Age phải >= 0")

    return age


print(set_age(18))
```

---

# 13. Custom Exception

```python
class InvalidAgeError(Exception):
    pass
```

Sử dụng:

```python
class InvalidAgeError(Exception):
    pass


def register(age):
    if age < 18:
        raise InvalidAgeError("Phải đủ 18 tuổi")


register(16)
```

Kết quả:

```text
InvalidAgeError:
Phải đủ 18 tuổi
```

---

# 14. Bắt Custom Exception

```python
try:
    register(16)

except InvalidAgeError as error:
    print(error)
```

---

# 15. Thứ tự `except`

Sai:

```python
try:
    ...

except Exception:
    ...

except ValueError:
    ...
```

`ValueError` sẽ **không bao giờ được thực thi**.

Đúng:

```python
try:
    ...

except ValueError:
    ...

except Exception:
    ...
```

Luôn bắt Exception **cụ thể trước**, tổng quát sau.

---

# 16. Không nên dùng `except:` trống

Không nên:

```python
try:
    ...
except:
    print("Có lỗi")
```

Bạn sẽ không biết lỗi gì xảy ra.

Nên:

```python
except Exception as error:
    print(error)
```

---

# 17. Re-raise Exception

```python
try:
    int("abc")

except ValueError:
    print("Lỗi!")

    raise
```

Kết quả:

```text
Lỗi!
ValueError
```

`raise` không có tham số sẽ ném lại ngoại lệ hiện tại.

---

# 18. Chuỗi Exception

```python
try:
    int("abc")

except ValueError as error:
    raise RuntimeError("Lỗi xử lý dữ liệu") from error
```

Kết quả sẽ hiển thị cả nguyên nhân gốc (`ValueError`) và ngoại lệ mới (`RuntimeError`).

---

# 19. Best Practices

## Chỉ bắt Exception khi có thể xử lý

Không nên:

```python
try:
    process_data()
except Exception:
    pass
```

Lỗi sẽ bị "nuốt" và rất khó debug.

---

## Bắt đúng loại Exception

Tốt:

```python
try:
    number = int(text)

except ValueError:
    print("Không phải số.")
```

---

## Không dùng Exception để thay thế điều kiện

Không nên:

```python
try:
    if age < 18:
        raise Exception()

except:
    ...
```

Nên:

```python
if age < 18:
    print("Chưa đủ tuổi")
```

---

## Ghi log lỗi

```python
import logging

logging.basicConfig(level=logging.ERROR)

try:
    int("abc")

except ValueError:
    logging.exception("Lỗi chuyển đổi")
```

Trong dự án thực tế, ghi log quan trọng hơn việc chỉ `print()`.

# 20. Ví dụ thực tế

## Máy tính chia hai số

```python
try:
    a = float(input("A: "))
    b = float(input("B: "))

    print(a / b)

except ValueError:
    print("Bạn phải nhập số.")

except ZeroDivisionError:
    print("Không thể chia cho 0.")

else:
    print("Tính toán thành công.")

finally:
    print("Kết thúc chương trình.")
```

---

## Đọc tệp

```python
try:
    with open("data.txt") as file:
        print(file.read())

except FileNotFoundError:
    print("Không tìm thấy tệp.")
```

---

## Kiểm tra mật khẩu

```python
class WeakPasswordError(Exception):
    pass


def validate(password):
    if len(password) < 8:
        raise WeakPasswordError("Mật khẩu quá ngắn.")


try:
    validate("12345")

except WeakPasswordError as error:
    print(error)
```

# 21. Các Exception phổ biến

| Exception             | Ý nghĩa                              |
| --------------------- | ------------------------------------ |
| `ValueError`          | Giá trị không hợp lệ                 |
| `TypeError`           | Sai kiểu dữ liệu                     |
| `IndexError`          | Chỉ số vượt phạm vi                  |
| `KeyError`            | Không tìm thấy khóa trong Dictionary |
| `NameError`           | Biến chưa được định nghĩa            |
| `AttributeError`      | Đối tượng không có thuộc tính        |
| `ZeroDivisionError`   | Chia cho 0                           |
| `FileNotFoundError`   | Không tìm thấy tệp                   |
| `ImportError`         | Lỗi import module                    |
| `ModuleNotFoundError` | Không tìm thấy module                |
| `RuntimeError`        | Lỗi khi thực thi                     |
| `PermissionError`     | Không có quyền truy cập              |
| `KeyboardInterrupt`   | Người dùng nhấn `Ctrl + C`           |

# 22. Những lỗi thường gặp

## Lỗi 1: Bắt `Exception` quá sớm

```python
except Exception:
```

Điều này có thể che mất các lỗi cụ thể.

---

## Lỗi 2: `except: pass`

```python
try:
    ...
except:
    pass
```

Đây là một **anti-pattern** vì làm mất thông tin lỗi.

---

## Lỗi 3: Dùng Exception thay cho `if`

```python
try:
    raise Exception()
except:
    ...
```

Nên dùng điều kiện thông thường nếu không có lỗi bất thường.

---

# 23. Bài tập thực hành

## Bài 1

Viết chương trình:

* Nhập hai số nguyên.
* Chia số thứ nhất cho số thứ hai.
* Xử lý lỗi chia cho 0.

---

## Bài 2

Viết chương trình:

* Nhập tuổi.
* Nếu tuổi âm thì `raise ValueError`.

---

## Bài 3

Tạo `Custom Exception` tên:

```python
class InvalidScoreError(Exception):
    pass
```

Nếu điểm < 0 hoặc > 10 thì ném ngoại lệ.

---

## Bài 4

Viết chương trình đọc một tệp văn bản.

Nếu tệp không tồn tại, hiển thị thông báo phù hợp.

---

## Bài 5

Viết hàm:

```python
def divide(a, b): ...
```

Yêu cầu:

* Nếu `b == 0`, `raise ZeroDivisionError`.
* Nếu tham số không phải số (`int` hoặc `float`), `raise TypeError`.
* Nếu hợp lệ, trả về kết quả chia.
