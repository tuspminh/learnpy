# Giai đoạn 1 – Python Foundation

# Buổi 13. Dictionary (Từ điển)

> Nếu `List` là cấu trúc dữ liệu được sử dụng nhiều nhất thì **Dictionary (`dict`)** là cấu trúc dữ liệu **quan trọng nhất** trong Python. Gần như mọi framework Python (Flask, Django, FastAPI), dữ liệu JSON, cấu hình ứng dụng, kết quả API... đều dựa trên `dict`.

---

# Mục tiêu

Sau buổi học này, bạn sẽ:

* Hiểu Dictionary là gì.
* Biết cách tạo và sử dụng Dictionary.
* Thêm, sửa, xóa dữ liệu.
* Duyệt Dictionary.
* Hiểu `key` và `value`.
* Hiểu Hash Table.
* Phân biệt Dictionary với List và Set.
* Biết các ứng dụng thực tế của Dictionary.

---

# 1. Dictionary là gì?

Dictionary là tập hợp các cặp:

```text
key -> value
```

Ví dụ:

```python
student = {"name": "An", "age": 20, "city": "Hà Nội"}

print(student)
```

Kết quả:

```text
{'name': 'An', 'age': 20, 'city': 'Hà Nội'}
```

---

# 2. Kiểm tra kiểu dữ liệu

```python
student = {"name": "An"}

print(type(student))
```

Kết quả

```text
<class 'dict'>
```

---

# 3. Key và Value

Ví dụ

```python
student = {"name": "An", "age": 20, "city": "Hà Nội"}
```

Trong đó

| Key  | Value  |
| ---- | ------ |
| name | An     |
| age  | 20     |
| city | Hà Nội |

Key dùng để tra cứu Value.


# 5. Không có Index

Sai

```python
student = {"name": "An"}

print(student[0])
```

Lỗi

```text
KeyError: 0
```

Dictionary truy cập bằng **key**, không phải index.

# 13. Xóa phần tử


# 14. Duyệt Dictionary

## Chỉ lấy Key

```python
student = {"name": "An", "age": 20}

for key in student:
    print(key)
```

Kết quả

```text
name
age
```

---

## Duyệt key rõ ràng

```python
for key in student.keys():
    print(key)
```

---

## Duyệt Value

```python
for value in student.values():
    print(value)
```

Kết quả

```text
An
20
```

---

## Duyệt Key và Value

```python
for key, value in student.items():
    print(key, value)
```

Kết quả

```text
name An
age 20
```

Đây là cách được sử dụng nhiều nhất.

---

# 15. get()

Sai

```python
student = {"name": "An"}

print(student["age"])
```

Lỗi

```text
KeyError
```

Đúng

```python
print(student.get("age"))
```

Kết quả

```text
None
```

---

Có giá trị mặc định

```python
print(student.get("age", 0))
```

```text
0
```

---

# 16. update()

```python
student = {"name": "An"}

student.update({"age": 20, "city": "Huế"})

```

Kết quả

```text
{
'name':'An',
'age':20,
'city':'Huế'
}
```

# 20. Dictionary giữ thứ tự

Từ Python 3.7 trở lên, Dictionary giữ nguyên thứ tự chèn phần tử.

```python
data = {}

data["b"] = 2
data["a"] = 1
data["c"] = 3

print(data)
```

Kết quả

```text
{'b': 2, 'a': 1, 'c': 3}
```

---

# 21. So sánh List, Tuple, Set, Dictionary

| Kiểu  | Có thứ tự | Mutable | Trùng        | Truy cập |
| ----- | --------- | ------- | ------------ | -------- |
| List  | ✅         | ✅       | ✅            | Index    |
| Tuple | ✅         | ❌       | ✅            | Index    |
| Set   | ❌         | ✅       | ❌            | Không    |
| Dict  | ✅         | ✅       | Key duy nhất | Key      |

# 22. Ví dụ thực tế

## Danh bạ

```python
phone_book = {"An": "0901111111", "Lan": "0902222222", "Hoa": "0903333333"}

name = input("Tên: ")

print(phone_book.get(name, "Không tìm thấy"))
```

---

## Đếm số lần xuất hiện

```python
text = "python python java python c"

counter = {}

for word in text.split():
    if word in counter:
        counter[word] += 1
    else:
        counter[word] = 1

print(counter)
```

Kết quả

```text
{
'python':3,
'java':1,
'c':1
}
```

# 23. Những lỗi thường gặp

## Truy cập Key không tồn tại

Sai

```python
student["phone"]
```

Dùng

```python
student.get("phone")
```

---

## Dùng List làm Key

Sai

```python
{[1, 2]: 100}
```

---

## Nhầm giữa key và value

Sai

```python
if 20 in student:
```

Điều này kiểm tra **key**, không phải value.

Đúng

```python
20 in student.values()
```

# Tổng kết

Trong buổi học này, bạn đã học:

* Khái niệm `Dictionary` và cấu trúc **key–value**.
* Thêm, sửa, xóa và truy cập dữ liệu.
* Duyệt `dict` bằng `keys()`, `values()` và `items()`.
* Sử dụng `get()` để tránh `KeyError`.
* Dictionary lồng nhau và kết hợp với `list`.
* Khái niệm **hashable key**.
* Ứng dụng của `dict` trong các bài toán thực tế như danh bạ và đếm tần suất.

## Chuẩn bị cho buổi 14

Ở **Buổi 14**, chúng ta sẽ học **Hàm (Function)**, một trong những nền tảng quan trọng nhất của lập trình. Bạn sẽ học cách:

* Định nghĩa và gọi hàm.
* Tham số (parameters) và đối số (arguments).
* Giá trị trả về (`return`).
* Biến cục bộ và phạm vi cơ bản.
