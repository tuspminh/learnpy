# Giai đoạn 1 – Python Foundation

# Buổi 12. Set (Tập hợp)

> `set` là một trong những kiểu dữ liệu bị người mới học Python bỏ qua nhiều nhất. Tuy nhiên, trong các dự án thực tế, `set` được sử dụng rất nhiều để **loại bỏ dữ liệu trùng lặp**, **kiểm tra phần tử có tồn tại hay không với tốc độ rất nhanh**, và thực hiện các **phép toán tập hợp**.

---

# Mục tiêu

Sau buổi học này, bạn sẽ:

* Hiểu Set là gì.
* Biết cách tạo Set.
* Hiểu vì sao Set không có thứ tự.
* Hiểu vì sao Set không chứa phần tử trùng lặp.
* Thêm, xóa phần tử.
* Duyệt Set.
* Thực hiện các phép toán tập hợp.
* Hiểu Hash và Hashable.
* Biết khi nào nên dùng Set thay vì List.

---

# 1. Set là gì?

Set là một tập hợp các phần tử:

* Không có thứ tự (unordered)
* Không có index
* Không chứa phần tử trùng lặp
* Có thể thay đổi (mutable)

Ví dụ:

```python
numbers = {1, 2, 3, 4}
```

Kiểm tra kiểu dữ liệu:

```python
numbers = {1, 2, 3}

print(type(numbers))
```

Kết quả:

```text
<class 'set'>
```

---

# 2. Set tự loại bỏ phần tử trùng

```python
numbers = {1, 2, 3, 2, 1, 5, 3}

print(numbers)
```

Kết quả:

```text
{1, 2, 3, 5}
```

Python tự loại bỏ phần tử trùng.

Đây là đặc điểm quan trọng nhất của Set.

---

# 3. Set không có thứ tự

Ví dụ:

```python
colors = {"red", "green", "blue"}

print(colors)
```

Có thể in ra:

```text
{'green', 'red', 'blue'}
```

Hoặc:

```text
{'blue', 'green', 'red'}
```

> **Lưu ý:** Thứ tự hiển thị của `set` không được đảm bảo. Không nên viết chương trình phụ thuộc vào thứ tự của Set.

---

# 4. Không truy cập bằng index

Sai:

```python
colors = {"red", "green", "blue"}

print(colors[0])
```

Lỗi:

```text
TypeError: 'set' object is not subscriptable
```

Set không hỗ trợ chỉ số (`index`).

---

# 5. Tạo Set từ List

```python
numbers = [1, 2, 2, 3, 4, 4, 5]

unique = set(numbers)

print(unique)
```

Kết quả:

```text
{1, 2, 3, 4, 5}
```

Đây là cách phổ biến nhất để loại bỏ phần tử trùng.

---

# 6. Tạo Set rỗng

Sai:

```python
data = {}
```

Kết quả:

```python
print(type(data))
```

```text
<class 'dict'>
```

`{}` là Dictionary rỗng, **không phải Set**.

Đúng:

```python
data = set()

print(type(data))
```

```text
<class 'set'>
```

---

# 7. Thêm phần tử

Sử dụng `add()`.

```python
numbers = {1, 2, 3}

numbers.add(4)

print(numbers)
```

Kết quả:

```text
{1, 2, 3, 4}
```

---

Thêm phần tử đã tồn tại:

```python
numbers.add(4)

print(numbers)
```

Không có gì thay đổi.

---

# 8. Thêm nhiều phần tử

Dùng `update()`.

```python
numbers = {1, 2}

numbers.update([3, 4, 5])

print(numbers)
```

Kết quả:

```text
{1, 2, 3, 4, 5}
```

---

Có thể truyền Set:

```python
numbers.update({6, 7})
```

Hoặc Tuple:

```python
numbers.update((8, 9))
```

---

# 9. Xóa phần tử

## remove()

```python
numbers = {1, 2, 3}

numbers.remove(2)

print(numbers)
```

Kết quả:

```text
{1, 3}
```

Nếu phần tử không tồn tại:

```python
numbers.remove(100)
```

Lỗi:

```text
KeyError
```

---

## discard()

```python
numbers.discard(100)
```

Không báo lỗi.

Đây là điểm khác biệt lớn giữa `remove()` và `discard()`.

---

## pop()

```python
numbers = {1, 2, 3}

item = numbers.pop()

print(item)
print(numbers)
```

`pop()` lấy và xóa **một phần tử bất kỳ**, không phải phần tử đầu tiên hay cuối cùng.

---

## clear()

```python
numbers.clear()

print(numbers)
```

Kết quả:

```text
set()
```

---

# 10. Kiểm tra phần tử

```python
numbers = {10, 20, 30}

print(20 in numbers)
```

Kết quả:

```text
True
```

---

```python
print(100 in numbers)
```

```text
False
```

Một trong những ưu điểm lớn của Set là việc kiểm tra phần tử rất nhanh.

---

# 11. Duyệt Set

```python
colors = {"red", "green", "blue"}

for color in colors:
    print(color)
```

Do Set không có thứ tự nên thứ tự in có thể khác nhau.

---

# 12. Độ dài Set

```python
numbers = {1, 2, 3, 4}

print(len(numbers))
```

Kết quả:

```text
4
```

# 13. Hợp (Union)

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
```

Kết quả:

```text
{1, 2, 3, 4, 5}
```

Hoặc:

```python
print(a.union(b))
```

---

# 14. Giao (Intersection)

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a & b)
```

Kết quả:

```text
{2, 3}
```

Hoặc:

```python
print(a.intersection(b))
```

---

# 15. Hiệu (Difference)

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a - b)
```

Kết quả:

```text
{1}
```

---

# 16. Hiệu đối xứng (Symmetric Difference)

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a ^ b)
```

Kết quả:

```text
{1, 4}
```

Hoặc:

```python
print(a.symmetric_difference(b))
```

---

# 17. Tập con

```python
a = {1, 2}
b = {1, 2, 3}

print(a <= b)
```

Kết quả:

```text
True
```

Hoặc:

```python
print(a.issubset(b))
```

---

# 18. Tập cha

```python
b = {1, 2, 3}

a = {1, 2}

print(b >= a)
```

Kết quả:

```text
True
```

Hoặc:

```python
print(b.issuperset(a))
```

# 19. Hash và Hashable

Set sử dụng **Hash Table** để lưu dữ liệu.

Điều này có nghĩa:

Chỉ những đối tượng **hashable** mới được đưa vào Set.

Ví dụ đúng:

```python
data = {1, 2, 3}
```

```python
data = {"Python", "Java"}
```

```python
data = {(1, 2), (3, 4)}
```

---

Sai:

```python
data = {[1, 2], [3, 4]}
```

Lỗi:

```text
TypeError: unhashable type: 'list'
```

Vì `list` là mutable nên không hash được.

# 20. Khi nào dùng Set?

## Loại bỏ phần tử trùng

```python
names = ["An", "Lan", "An", "Hoa", "Lan"]

unique = set(names)

print(unique)
```

---

## Kiểm tra tồn tại

Ví dụ kiểm tra quyền truy cập:

```python
permissions = {"read", "write", "delete"}

if "delete" in permissions:
    print("Có quyền xóa.")
```

Set thường nhanh hơn List khi kiểm tra phần tử.

---

# 21. So sánh List và Set

| Tiêu chí          | List     | Set       |
| ----------------- | -------- | --------- |
| Có thứ tự         | ✅        | ❌         |
| Có index          | ✅        | ❌         |
| Chứa trùng        | ✅        | ❌         |
| Mutable           | ✅        | ✅         |
| Kiểm tra `in`     | Chậm hơn | Nhanh hơn |
| Phép toán tập hợp | ❌        | ✅         |

---

# 22. Ví dụ thực tế

Đếm số từ khác nhau trong một câu:

```python
text = "python java python c java python"

words = text.split()

unique_words = set(words)

print("Các từ:", unique_words)
print("Số từ khác nhau:", len(unique_words))
```

Ví dụ kết quả:

```text
Các từ: {'python', 'java', 'c'}
Số từ khác nhau: 3
```

---

Tìm học sinh có mặt ở cả hai lớp:

```python
class_a = {"An", "Bình", "Lan", "Hoa"}
class_b = {"Lan", "Hoa", "Minh"}

common = class_a & class_b

print(common)
```

Kết quả:

```text
{'Lan', 'Hoa'}
```

# 23. Những lỗi thường gặp

## Dùng `{}` để tạo Set rỗng

Sai:

```python
s = {}
```

Đúng:

```python
s = set()
```

---

## Truy cập bằng index

Sai:

```python
numbers = {1, 2, 3}

print(numbers[0])
```

---

## Thêm List vào Set

Sai:

```python
data = {1, 2}

data.add([3, 4])
```

Lỗi:

```text
TypeError: unhashable type: 'list'
```

---

## Cho rằng `pop()` luôn xóa phần tử đầu tiên

Không đúng.

```python
numbers = {1, 2, 3}

print(numbers.pop())
```

Phần tử được lấy ra là **bất kỳ**, không nên dựa vào thứ tự.
