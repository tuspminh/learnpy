# 1. List là gì?

List là một **danh sách có thứ tự**, chứa nhiều phần tử.

Ví dụ:

```python
numbers = [1, 2, 3, 4, 5]
```

Danh sách tên:

```python
names = ["An", "Bình", "Lan", "Hoa"]
```

Danh sách hỗn hợp:

```python
data = [10, "Python", True, 3.14]
```

Python cho phép List chứa nhiều kiểu dữ liệu khác nhau.

# 16. List là tham chiếu (Reference)

Đây là phần rất quan trọng.

```python
a = [1, 2, 3]

b = a
```

Bộ nhớ

```text
a ─────┐
       │
       ▼
   [1,2,3]
       ▲
       │
b ─────┘
```

Có **hai biến cùng trỏ tới một List**.

---

Ví dụ

```python
a = [1, 2, 3]

b = a

b[0] = 999

print(a)
```

Kết quả

```text
[999, 2, 3]
```

Nhiều người mới học rất dễ bất ngờ vì thay đổi `b` cũng làm thay đổi `a`.

---

# 17. Sao chép List

Muốn tạo một List mới độc lập, dùng `copy()` hoặc slicing.

```python
a = [1, 2, 3]

b = a.copy()

b[0] = 100

print(a)
print(b)
```

Kết quả

```text
[1, 2, 3]
[100, 2, 3]
```

Hoặc:

```python
b = a[:]
```

> Lưu ý: Đây là **shallow copy** (sao chép nông). Khi học về dữ liệu lồng nhau, chúng ta sẽ tìm hiểu **deep copy**.

# 18. So sánh List

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)
```

```text
True
```

So sánh nội dung.

---

```python
print(a is b)
```

```text
False
```

`is` so sánh hai biến có cùng tham chiếu đến một đối tượng hay không.

Ví dụ:

```python
a = [1, 2, 3]
b = a

print(a is b)
```

```text
True
```

# 19. Một số lỗi thường gặp

## Truy cập ngoài phạm vi

```python
numbers = [1, 2, 3]

print(numbers[5])
```

Lỗi:

```text
IndexError: list index out of range
```

---

## Nhầm lẫn giữa `=` và `==`

```python
numbers = [1, 2, 3]

numbers[0] = 100
```

Là gán giá trị.

```python
numbers[0] == 100
```

Là so sánh.

---

## Nhầm lẫn khi sao chép

Sai:

```python
a = [1, 2, 3]

b = a
```

Đúng nếu muốn bản sao:

```python
b = a.copy()
```

# 20. Ví dụ thực tế

Quản lý điểm của học sinh.

```python
scores = [8.5, 7.0, 9.0, 6.5]

print("Danh sách điểm:")

for score in scores:
    print(score)
```

---

Tìm điểm cao nhất (không dùng hàm `max`).

```python
scores = [8.5, 7.0, 9.0, 6.5]

highest = scores[0]

for score in scores:
    if score > highest:
        highest = score

print("Điểm cao nhất:", highest)
```

Kết quả:

```text
Điểm cao nhất: 9.0
```
