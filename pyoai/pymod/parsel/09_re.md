# Buổi 9 — `re()` Deep Dive (Regular Expression trong Parsel)

Trong các buổi trước, chúng ta đã học:

* `css()`
* `xpath()`
* `get()`
* `getall()`

Những công cụ này rất mạnh, nhưng có nhiều trường hợp dữ liệu nằm **bên trong text**, **JavaScript**, hoặc **attribute** mà CSS/XPath không thể tách trực tiếp.

Ví dụ:

```html
<span>Giá: 1.250.000₫</span>
```

Bạn chỉ muốn lấy:

```
1250000
```

Hoặc

```html
<script>

var chapterId = 12345;

var storyId = 987;

</script>
```

Bạn muốn lấy:

```
12345
987
```

Lúc này, `re()` là công cụ phù hợp.

# 1. `re()` là gì?

`re()` thực hiện:

> Áp dụng biểu thức chính quy (Regular Expression) lên nội dung của Selector hoặc SelectorList và trả về tất cả kết quả khớp.

Ví dụ

```html
<span>Price: 100 USD</span>
```

Parser

```python
sel.css("span::text").re(r"\d+")
```

↓

```python
["100"]
```

---

# 2. Cú pháp

```python
selector.re(pattern)
```

Ví dụ

```python

```

# 20. `re()` trên HTML

Nếu bạn không chọn `::text`:

```python
book.css(".price").re(r"\d+")
```

Regex sẽ chạy trên HTML của node:

```html
<span class="price">

Price: 150 USD

</span>
```

Kết quả vẫn có thể là:

```python
["150"]
```

Nhưng điều này không được khuyến khích vì regex sẽ quét cả phần markup HTML.

Nên dùng:

```python
book.css(".price::text").re(...)
```

# 22. Best Practices

### Luôn dùng CSS/XPath trước

Đúng:

```python
book.css(".price::text").re(r"\d+")
```

Không nên:

```python
sel.re(r"\d+")
```

vì sẽ quét toàn bộ tài liệu.

---

### Kiểm tra kết quả trước khi truy cập

```python
result = book.css(".price::text").re(r"\d+")

price = int(result[0]) if result else 0
```

---

### Regex chỉ làm việc cuối cùng

Quy trình nên là:

```
CSS/XPath
        ↓
Chọn đúng node
        ↓
Lấy text/attribute
        ↓
Regex
        ↓
Chuyển kiểu dữ liệu
```

---

### Đặt tên regex rõ ràng

```python
PRICE_PATTERN = r"[\d\.]+"
RATING_PATTERN = r"\d+\.\d+"
EMAIL_PATTERN = r"[\w\.-]+@[\w\.-]+\.\w+"
```

Thay vì viết trực tiếp ở nhiều nơi.

# 23. Ví dụ hoàn chỉnh

```python
from parsel import Selector

html = """
<div class="book">
    <h2>Python Deep Dive</h2>
    <span class="price">Price: 1.250.000₫</span>
    <p>Rating: 4.8</p>
</div>
"""

sel = Selector(text=html)

book = sel.css(".book")[0]

price_match = book.css(".price::text").re(r"[\d\.]+")
rating_match = book.css("p::text").re(r"\d+\.\d+")

price = int(price_match[0].replace(".", "")) if price_match else 0

rating = float(rating_match[0]) if rating_match else 0.0

data = {
    "title": book.css("h2::text").get(default="").strip(),
    "price": price,
    "rating": rating,
}

print(data)
```

Kết quả:

```python
{
    "title": "Python Deep Dive",
    "price": 1250000,
    "rating": 4.8,
}
```

Cho HTML:

Hãy viết parser để tạo:

```python
{
    "title": "Thế Giới Hoàn Mỹ",
```

2. Dùng `re()` để trích xuất các số.
3. Chuyển dữ liệu sang `int`.
4. Không để parser bị lỗi nếu thiếu một trong các trường.

# Tổng kết

`re()` là cầu nối giữa **Selector** và **Regular Expression**. Nó đặc biệt hữu ích khi dữ liệu không thể tách trực tiếp bằng CSS hoặc XPath, như giá tiền, ID trong URL, dữ liệu JavaScript hay các chuỗi có định dạng phức tạp.

Trong thực tế, quy trình tối ưu gần như luôn là:

```text
CSS/XPath
    ↓
get() hoặc getall() (nếu cần)
    ↓
re() để trích xuất phần mong muốn
    ↓
Làm sạch dữ liệu
    ↓
Chuyển kiểu dữ liệu
```

Ở **Buổi 10**, chúng ta sẽ học **`re_first()`** — phương thức lấy **kết quả regex đầu tiên**, giúp mã nguồn ngắn gọn và an toàn hơn khi bạn chỉ cần một giá trị duy nhất thay vì cả danh sách.
