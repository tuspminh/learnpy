## 🎯 PROJECT XUYÊN SUỐT (Áp dụng toàn bộ kiến thức)
**"Hệ thống quản lý thư viện cá nhân"** - qua từng bài học, bạn sẽ:
- Lưu sách bằng dict/list → lên class Book/Library
- Lưu file JSON → thêm tính năng import/export
- Viết unit test → đảm bảo chất lượng
- Thêm decorator đo thời gian truy vấn
- Cuối cùng là CLI hoặc GUI đơn giản
