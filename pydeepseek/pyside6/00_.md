### Tuần 1: Làm quen & Vòng đời ứng dụng

Mục tiêu: Cài đặt, chạy ứng dụng đầu tiên, hiểu rõ luồng hoạt động của một ứng dụng đồ họa.

#### 1. Cài đặt

```bash
pip install pyside6
```

#### 2. Ứng dụng "Xin chào thế giới" đầu tiên

```python
# main.py
import sys
from PySide6.QtWidgets import QApplication, QLabel

# 1. Tạo đối tượng QApplication (BẮT BUỘC, chỉ có 1 duy nhất)
app = QApplication(sys.argv)

# 2. Tạo một Widget (thành phần giao diện)
label = QLabel("Xin chào, PySide6!")
label.setWindowTitle("Ứng dụng đầu tiên của tôi")

# 3. Hiển thị widget
label.show()

# 4. Bắt đầu vòng lặp sự kiện (Event Loop)
sys.exit(app.exec())
```

#### 3. Giải thích chi tiết

-   `QApplication`: Đây là "trái tim" của ứng dụng. Nó quản lý vòng lặp sự kiện, cài đặt toàn cục (như phông chữ, màu sắc), và xử lý các sự kiện từ hệ điều hành (bàn phím, chuột,...). Bạn chỉ có **duy nhất một** `QApplication` trong toàn bộ chương trình.

-   `QWidget`: Đây là lớp cơ sở cho MỌI thành phần giao diện trong Qt. Một `QWidget` có thể là một cửa sổ độc lập (như `QLabel` ở trên) hoặc là một thành phần con nằm bên trong một cửa sổ khác (như một nút bấm, ô nhập liệu).

-   `.show()`: Phương thức này báo hiệu cho hệ điều hành rằng bạn muốn hiển thị widget này. Mặc định, widget sẽ ở trạng thái ẩn (hidden) cho đến khi bạn gọi `show()`.

-   `app.exec()`: Đây là **Vòng lặp sự kiện chính (Main Event Loop)**.
    -   Đây là một vòng lặp vô hạn, nó liên tục lắng nghe và xử lý các sự kiện từ người dùng (nhấp chuột, gõ phím) và từ hệ điều hành (cửa sổ cần vẽ lại, cửa sổ bị thu nhỏ,...).
    -   Chương trình của bạn sẽ "dừng" lại ở dòng này và chỉ kết thúc khi bạn tắt cửa sổ chính hoặc gọi `app.quit()`.
    -   `sys.exit(app.exec())` đảm bảo rằng khi ứng dụng kết thúc, nó sẽ trả về mã thoát chính xác cho hệ điều hành.

#### 4. Vòng đời của một ứng dụng

1.  **Khởi tạo `QApplication`**.
2.  **Tạo và cấu hình `QWidget`** (cửa sổ chính).
3.  **Hiển thị cửa sổ** (`.show()`).
4.  **Chạy vòng lặp sự kiện** (`app.exec()`).
5.  **Vòng lặp lắng nghe**:
    -   Người dùng nhấn nút -> Gửi sự kiện "click".
    -   Ứng dụng nhận và gọi hàm xử lý của bạn.
    -   Cửa sổ cần vẽ lại -> Gửi sự kiện "paint".
    -   Ứng dụng vẽ lại cửa sổ.
6.  **Người dùng tắt cửa sổ** -> Gửi sự kiện "close".
7.  **Ứng dụng giải phóng tài nguyên và thoát**.

### Tuần 2: Layouts & Widgets cơ bản

Mục tiêu: Biết cách sắp xếp các thành phần và sử dụng các widget phổ biến.

#### 1. Layout (Bố cục) - "Sếp" của các Widget

**Nguyên tắc quan trọng:** KHÔNG BAO GIỜ đặt kích thước cố định cho cửa sổ và widget nếu không cần thiết. Hãy để **Layout** tự động sắp xếp và co giãn chúng. Điều này giúp ứng dụng của bạn hiển thị đẹp trên mọi kích thước màn hình và khi người dùng kéo thả để thay đổi kích thước cửa sổ.

-   `QVBoxLayout`: Xếp các widget theo **hàng dọc**.
-   `QHBoxLayout`: Xếp các widget theo **hàng ngang**.
-   `QGridLayout`: Xếp các widget theo **dạng bảng (lưới)**.

**Ví dụ: Layout lồng nhau (Nested Layouts) - Kỹ thuật cực kỳ quan trọng**

```python
import sys
from PySide6.QtWidgets import (
    QApplication,
    QWidget,
    QVBoxLayout,
    QHBoxLayout,
    QPushButton,
    QLabel,
    QLineEdit,
)


class MainWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Ví dụ Layout")

        # 1. Tạo các widget
        label = QLabel("Tên của bạn:")
        name_input = QLineEdit()
        name_input.setPlaceholderText("Nhập tên vào đây...")
        submit_btn = QPushButton("Gửi")
        cancel_btn = QPushButton("Hủy")

        # 2. Tạo Layout con (ngang) để chứa 2 nút
        button_layout = QHBoxLayout()
        button_layout.addWidget(submit_btn)
        button_layout.addWidget(cancel_btn)

        # 3. Tạo Layout chính (dọc) để chứa mọi thứ
        main_layout = QVBoxLayout()
        main_layout.addWidget(label)  # Thêm widget
        main_layout.addWidget(name_input)  # Thêm widget
        main_layout.addLayout(button_layout)  # THÊM MỘT LAYOUT VÀO LAYOUT KHÁC

        # 4. Gán layout cho cửa sổ chính
        self.setLayout(main_layout)


if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

#### 2. Một số Widget cơ bản bạn cần biết

-   `QLabel`: Hiển thị văn bản hoặc hình ảnh.
-   `QPushButton`: Nút bấm.
-   `QLineEdit`: Ô nhập văn bản một dòng.
-   `QTextEdit`: Ô nhập văn bản nhiều dòng (có hỗ trợ định dạng).
-   `QCheckBox`: Ô chọn (có/không).
-   `QRadioButton`: Nút tròn chọn một trong nhiều lựa chọn (thường nằm trong `QButtonGroup`).
-   `QComboBox`: Hộp chọn thả xuống.

### Tuần 3: Sự kiện (Event) & Signals/Slots

Mục tiêu: Làm cho ứng dụng phản hồi lại hành động của người dùng.

#### 1. Cơ chế Signals & Slots - "Linh hồn" của PySide6

Đây là một cơ chế giao tiếp giữa các đối tượng. Nó cực kỳ an toàn và linh hoạt.

-   **Signal (Tín hiệu)**: Một sự kiện được phát ra khi có điều gì đó xảy ra (ví dụ: nút được nhấn, văn bản thay đổi).
-   **Slot (Khe cắm)**: Một hàm (method) sẽ được gọi để phản hồi lại tín hiệu đó.

**Cú pháp cơ bản:**

```python
# Kết nối: signal của đối tượng A -> slot của đối tượng B (hoặc chính nó)
# signal_object.signal_name.connect(slot_function)
```

**Ví dụ thực tế:**

```python
import sys
from PySide6.QtWidgets import QApplication, QWidget, QPushButton, QLabel, QVBoxLayout


class MainWindow(QWidget):
    def __init__(self):
        super().__init__()
        self.setWindowTitle("Signals & Slots")

        # Tạo widget
        self.label = QLabel("Chưa nhấn gì cả")
        button = QPushButton("Nhấn vào tôi!")

        # Layout
        layout = QVBoxLayout()
        layout.addWidget(self.label)
        layout.addWidget(button)
        self.setLayout(layout)

        # --- PHẦN QUAN TRỌNG: Kết nối Signal & Slot ---
        # clicked là một Signal của QPushButton
        # self.on_button_clicked là Slot (hàm xử lý)
        button.clicked.connect(self.on_button_clicked)

    # Đây là Slot
    def on_button_clicked(self):
        # Sửa đổi text của label khi button được click
        self.label.setText("Bạn vừa nhấn nút!")


if __name__ == "__main__":
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

#### 2. Gửi dữ liệu qua Signal

Hầu hết các signal đều gửi kèm dữ liệu. Ví dụ: `QLineEdit` có signal `textChanged` gửi kèm chuỗi văn bản mới.

```python
class MainWindow(QWidget):
    def __init__(self):
        # ... (tạo QLineEdit và QLabel) ...
        self.line_edit = QLineEdit()
        self.label = QLabel("Bạn đang gõ: ")

        # Slot của chính nó, nhận vào một tham số là text
        self.line_edit.textChanged.connect(self.on_text_changed)

    def on_text_changed(self, text):
        # text là dữ liệu được gửi từ signal textChanged
        self.label.setText(f"Bạn đang gõ: {text}")
```

#### 3. Tự tạo Signal (Nâng cao, nhưng rất hữu ích)

Bạn có thể tạo signal cho riêng class của mình để giao tiếp giữa các thành phần phức tạp.

```python
from PySide6.QtCore import Signal, QObject


# Một class không phải widget, nhưng vẫn có thể có Signal
class MyCommunicator(QObject):
    # Định nghĩa một signal mới, có thể gửi kèm 1 chuỗi và 1 số nguyên
    data_ready = Signal(str, int)

    def do_something(self):
        # Phát ra signal khi có dữ liệu mới
        self.data_ready.emit("Hello", 123)


# Sử dụng:
# communicator = MyCommunicator()
# communicator.data_ready.connect(my_slot_function)
```
