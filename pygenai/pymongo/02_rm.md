Lộ trình học bài bản và hệ thống từ cơ bản đến nâng cao để làm chủ **MongoDB với Python**, được chia làm 4 giai đoạn rõ ràng.

---

## **Giai đoạn 1: Nền tảng MongoDB & PyMongo Cơ bản**

> **Mục tiêu:** Nắm vững cú pháp cơ bản, kết nối Python với MongoDB và thành thạo các thao tác CRUD cơ bản.

### 1. Kiến thức nền tảng về NoSQL & MongoDB

* So sánh SQL (Bảng, Dòng, Cột) vs NoSQL Document (Database, Collection, Document).
* Khái niệm định dạng **BSON** (Binary JSON) và các kiểu dữ liệu hỗ trợ trong MongoDB.
* Cài đặt MongoDB Community Server + MongoDB Compass (GUI) hoặc tạo tài khoản MongoDB Atlas (Cloud).

### 2. Kết nối Python với `pymongo`

* Cài đặt thư viện: `pip install pymongo dnspython`.
* Khởi tạo `MongoClient`, chọn Database và Collection.
* Xử lý biến môi trường (`.env`) để bảo mật chuỗi kết nối (`URI`).

### 3. Thao tác CRUD Cơ bản

* **Create:** `insert_one()`, `insert_many()`. Hiểu cấu trúc trường `_id` (ObjectId).
* **Read:** `find_one()`, `find()` kết hợp vớiProjection (chỉ lấy các trường cần thiết).
* **Update:** `update_one()`, `update_many()` với toán tử `$set`, `$unset`, `$inc`.
* **Delete:** `delete_one()`, `delete_many()`.

## **Giai đoạn 2: Truy vấn & Biến đổi dữ liệu nâng cao**

> **Mục tiêu:** Làm chủ các toán tử tìm kiếm, lọc, sắp xếp, phân trang và xử lý mảng trong Document.

### 1. Toán tử truy vấn (Query Operators)

* **So sánh:** `$eq`, `$ne`, `$gt`, `$gte`, `$lt`, `$lte`, `$in`, `$nin`.
* **Logic:** `$and`, `$or`, `$not`, `$nor`.
* **Kiểm tra thuộc tính:** `$exists`, `$type`.
* **Truy vấn chuỗi:** Sử dụng `$regex` để tìm kiếm biểu thức chính quy.

### 2. Thao tác với Mảng (Array Operators)

* Tìm kiếm trong mảng: `$all`, `$elemMatch`, `$size`.
* Cập nhật mảng: `$push`, `$addToSet`, `$pop`, `$pull`, `$pullAll`.

### 3. Phân trang & Sắp xếp (Pagination & Sorting)

* Sử dụng `.sort()`, `.skip()`, `.limit()`.
* Kỹ thuật phân trang tối ưu hiệu năng (*Keyset Pagination* thay vì `.skip()` trên tập dữ liệu lớn).

## **Giai đoạn 3: Aggregation Framework & Tối ưu hóa**

> **Mục tiêu:** Xử lý dữ liệu phức tạp, phân tích báo cáo và tối ưu tốc độ truy vấn.

### 1. Aggregation Pipeline

* Khái niệm chuỗi xử lý (Pipeline) và các công đoạn (Stages):
* `$match`: Lọc dữ liệu.
* `$group`: Nhóm dữ liệu và dùng toán tử tích tụ (`$sum`, `$avg`, `$min`, `$max`, `$push`).
* `$project`: Biến đổi cấu trúc Output.
* `$sort`, `$limit`, `$skip`.
* `$unwind`: Tách mảng thành các document riêng biệt.
* `$lookup`: Kết hợp dữ liệu giữa các collection (tương tự `JOIN` trong SQL).



### 2. Thiết kế dữ liệu (Data Modeling)

* Chiến lược **Embedded Documents** (Nhúng) vs **Referenced Documents** (Tham chiếu ID).
* Các mô hình quan hệ: 1-1, 1-N, N-N trong NoSQL.

### 3. Indexing & Tối ưu hiệu năng

* Tạo Index bằng `create_index()` (Single field, Compound Index, Text Index).
* Phân tích hiệu năng câu lệnh bằng `.explain()`.

## **Giai đoạn 4: Lập trình ODM & Tích hợp Framework Web**

> **Mục tiêu:** Áp dụng vào dự án thực tế bằng cách sử dụng các thư viện ODM (Object-Document Mapper) và xây dựng REST API.

### 1. Sử dụng ODM trong Python

* **MongoEngine** (Đồng bộ - Sync): Định nghĩa Schema bằng Python Class, Validate dữ liệu tự động.
* **Beanie** hoặc **Motor** (Bất đồng bộ - Async): Sử dụng `asyncio` để tối ưu hiệu năng cho các ứng dụng hiện đại.

### 2. Tích hợp dự án thực tế

* Kết hợp MongoDB với **FastAPI** hoặc **Flask**.
* Quản lý kết nối (Connection Pooling) để tránh cạn kiệt kết nối khi lượng người dùng cao.
* Xử lý ngoại lệ (`pymongo.errors.PyMongoError`).
