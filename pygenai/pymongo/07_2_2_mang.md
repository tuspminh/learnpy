## Giai đoạn 2 - Bài 2: Thao tác với Mảng (Array Operators) trong PyMongo

Trong MongoDB, một trường (field) có thể chứa một danh sách/mảng các giá trị (ví dụ: danh sách kỹ năng, danh sách lịch sử đơn hàng, danh sách nhãn tag). Để làm việc hiệu quả với dữ liệu dạng mảng, MongoDB cung cấp các toán tử truy vấn và cập nhật chuyên dụng.

---

### 1. Truy vấn trên Mảng (Array Query Operators)

#### **1.1. Toán tử `$all**`

Dùng khi bạn muốn tìm các document mà mảng của chúng **chứa tất cả** các phần tử được chỉ định (không quan trọng thứ tự).

```python
from pymongo import MongoClient

client = MongoClient("mongodb://localhost:27017")
db = client["hoc_python_db"]
collection = db["nhan_vien"]

# Tìm nhân viên có CẢ HẠI kỹ năng: "Python" VÀ "MongoDB"
query_all = {
    "kynang": {
        "$all": ["Python", "MongoDB"]
    }
}

for nv in collection.find(query_all, {"_id": 0, "ten": 1, "kynang": 1}):
    print(nv)

```

#### **1.2. Toán tử `$size**`

Lọc document theo độ dài (số lượng phần tử) chính xác của mảng.

```python
# Tìm nhân viên có đúng 2 kỹ năng
query_size = {"kynang": {"$size": 2}}

```

#### **1.3. Toán tử `$elemMatch**`

Dùng khi mảng chứa các **Object/Document con** và bạn cần tìm một phần tử trong mảng thỏa mãn **đồng thời nhiều điều kiện**.

Giả sử dữ liệu có cấu trúc mảng dự án như sau:

```json
{
  "ten": "Nguyễn Văn A",
  "du_an": [
    {"ten_da": "App A", "vai_tro": "Leader", "nam": 2024},
    {"ten_da": "App B", "vai_tro": "Dev", "nam": 2025}
  ]
}

```

```python
# Tìm nhân viên có tham gia dự án với vai trò "Leader" VÀ trong năm 2024 trên CÙNG MỘT dự án
query_elem = {
    "du_an": {
        "$elemMatch": {
            "vai_tro": "Leader",
            "nam": 2024
        }
    }
}

```

### 2. Cập nhật Mảng (Array Update Operators)

#### **2.1. Thêm phần tử vào Mảng: `$push` và `$addToSet**`

* **`$push`**: Thêm phần tử vào cuối mảng (cho phép trùng lặp).
* **`$addToSet`**: Thêm phần tử vào mảng **chỉ khi phần tử đó chưa tồn tại** (tránh trùng lặp).

```python
# 1. Dùng $push: Thêm "Docker" vào mảng kynang của Nguyễn Văn A
collection.update_one(
    {"ten": "Nguyễn Văn A"},
    {"$push": {"kynang": "Docker"}}
)

# 2. Dùng $addToSet: Thêm "Python" (nếu chưa có thì thêm, có rồi thì bỏ qua)
collection.update_one(
    {"ten": "Nguyễn Văn A"},
    {"$addToSet": {"kynang": "Python"}}
)

# 3. Thêm NHIỀU phần tử cùng lúc bằng cách kết hợp với $each
collection.update_one(
    {"ten": "Nguyễn Văn A"},
    {"$addToSet": {"kynang": {"$each": ["AWS", "Git"]}}}
)

```

#### **2.2. Xóa phần tử khỏi Mảng: `$pull` và `$pop**`

* **`$pull`**: Xóa tất cả các phần tử khớp với giá trị hoặc điều kiện chỉ định.
* **`$pop`**: Xóa phần tử đầu tiên (`-1`) hoặc cuối cùng (`1`) của mảng.

```python
# 1. Dùng $pull: Xóa kỹ năng "Java" khỏi danh sách kỹ năng của nhân viên
collection.update_one(
    {"ten": "Lê Văn C"},
    {"$pull": {"kynang": "Java"}}
)

# 2. Dùng $pullAll: Xóa NHIỀU giá trị cụ thể cùng lúc
collection.update_one(
    {"ten": "Nguyễn Văn A"},
    {"$pullAll": {"kynang": ["AWS", "Docker"]}}
)

# 3. Dùng $pop: Xóa phần tử CUỐI CÙNG trong mảng kynang
collection.update_one(
    {"ten": "Nguyễn Văn A"},
    {"$pop": {"kynang": 1}}  # 1 = phần tử cuối, -1 = phần tử đầu
)

```

---

### Tổng kết các toán tử thao tác Mảng

| Thao tác | Toán tử | Công dụng |
| --- | --- | --- |
| **Truy vấn** | `$all` | Chứa tất cả giá trị trong danh sách |
|  | `$size` | Kiểm tra độ dài mảng |
|  | `$elemMatch` | Khớp nhiều điều kiện trên cùng 1 phần tử của mảng |
| **Thêm mới** | `$push` | Thêm vào cuối mảng (cho phép trùng) |
|  | `$addToSet` | Thêm vào mảng (không trùng lặp) |
| **Xóa bỏ** | `$pull` | Xóa phần tử theo giá trị/điều kiện |
|  | `$pop` | Xóa phần tử đầu (`-1`) hoặc cuối (`1`) |
