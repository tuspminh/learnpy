**sqlite3** là thư viện được tích hợp sẵn trong Python, cho phép bạn thao tác với cơ sở dữ liệu SQL thông qua một file cục bộ duy nhất mà không cần cài đặt phần mềm máy chủ (server) phức tạp.

Để bắt đầu, chúng ta sẽ xây dựng một chương trình quản lý thông tin cơ bản áp dụng chuẩn **CRUD** (Create - Read - Update - Delete). Bạn có thể mở một file Python (ví dụ `app.py`) và viết lần lượt các đoạn code dưới đây.

1. **Kết nối với Database:** Khởi tạo file cơ sở dữ liệu.
Mọi thao tác với SQL đều bắt đầu bằng việc mở kết nối. Nếu file `data.db` chưa tồn tại, Python sẽ tự động tạo nó trong cùng thư mục.

```python
import sqlite3

# Tạo kết nối đến file database
conn = sqlite3.connect('data.db')

# Khởi tạo cursor - "con trỏ" dùng để thực thi các câu lệnh SQL
cursor = conn.cursor()

```


2. **Tạo Bảng (Create Table):** Định nghĩa cấu trúc lưu trữ.
Cơ sở dữ liệu lưu thông tin dạng bảng (gồm cột và hàng). Chúng ta sẽ tạo bảng `NhanVien` với 3 cột: ID (tự động tăng), Tên, và Tuổi.

```python
# Dùng ba dấu nháy kép để viết câu lệnh SQL nhiều dòng cho dễ đọc
sql_tao_bang = """
CREATE TABLE IF NOT EXISTS NhanVien (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    ten TEXT NOT NULL,
    tuoi INTEGER
)
"""

cursor.execute(sql_tao_bang)

```


3. **Thêm Dữ Liệu (Insert):** Create - Chữ C trong CRUD.
Để thêm dữ liệu, chúng ta dùng lệnh `INSERT INTO`. **Lưu ý quan trọng:** Luôn dùng dấu `?` (placeholder) khi truyền biến vào SQL để tránh lỗi bảo mật SQL Injection.

```python
# 1. Thêm một người
cursor.execute("INSERT INTO NhanVien (ten, tuoi) VALUES (?, ?)", ("Nam", 25))

# 2. Thêm nhiều người cùng lúc
danh_sach = [
    ("Hoa", 22),
    ("Tuấn", 30),
    ("Lan", 28)
]
cursor.executemany("INSERT INTO NhanVien (ten, tuoi) VALUES (?, ?)", danh_sach)

# Phải gọi commit() để lưu các thay đổi vĩnh viễn vào file .db
conn.commit() 
print("Đã thêm dữ liệu thành công!")

```


4. **Đọc Dữ Liệu (Select):** Read - Chữ R trong CRUD.
Lệnh `SELECT` dùng để lấy dữ liệu ra khỏi bảng.

```python
# Lấy toàn bộ cột (*) từ bảng NhanVien
cursor.execute("SELECT * FROM NhanVien")

# fetchall() trả về tất cả kết quả dưới dạng một danh sách các tuple
ket_qua = cursor.fetchall()

print("--- Danh sách Nhân Viên ---")
for nhan_vien in ket_qua:
    print(f"ID: {nhan_vien[0]} | Tên: {nhan_vien[1]} | Tuổi: {nhan_vien[2]}")

```


5. **Cập nhật (Update) & Xóa (Delete):** Chữ U và D trong CRUD.
Khi sửa hoặc xóa, bạn luôn phải dùng kèm từ khóa `WHERE` để chỉ định chính xác hàng nào cần tác động. Nếu quên `WHERE`, toàn bộ bảng sẽ bị đổi/xóa.

```python
# Cập nhật tuổi của "Nam" thành 26
cursor.execute("UPDATE NhanVien SET tuoi = ? WHERE ten = ?", (26, "Nam"))

# Xóa nhân viên tên "Tuấn"
cursor.execute("DELETE FROM NhanVien WHERE ten = ?", ("Tuấn",))

# Đừng quên commit sau khi Update hoặc Delete
conn.commit()

```


6. **Đóng Kết Nối:**
Sau khi hoàn tất mọi thao tác, hãy đóng kết nối để giải phóng tài nguyên bộ nhớ cho hệ thống.

```python
conn.close()

```
