Kiến trúc cho ứng dụng CLI Text-to-Speech (TTS) được thiết kế theo các nguyên tắc **Clean Architecture** và **Domain-Driven Design (DDD)**, tối ưu cho việc mở rộng provider cũng như khôi phục state khi xử lý batch dung lượng lớn.

### 3. Split Text Service (Underthesea Boundary Splitter)

Sử dụng `underthesea.sent_tokenize` cho tiếng Việt để ngắt câu theo ngữ nghĩa trước khi gom thành các chunk 2000–3000 ký tự.

```python
# infrastructure/nlp/text_splitter.py
from underthesea import sent_tokenize
import re

class SmartTextSplitter:
    def __init__(self, min_chars: int = 2000, max_chars: int = 3000):
        self.min_chars = min_chars
        self.max_chars = max_chars

    def split(self, text: str, lang: str) -> list[str]:
        # Tách câu theo ngôn ngữ
        if lang == "vi":
            sentences = sent_tokenize(text)
        else:
            sentences = re.split(r'(?<=[.!?])\s+', text)

        chunks = []
        current_chunk = []
        current_length = 0

        for sentence in sentences:
            sent_len = len(sentence)
            
            # Quá giới hạn max_chars -> ngắt chunk hiện tại
            if current_length + sent_len > self.max_chars and current_length >= self.min_chars:
                chunks.append(" ".join(current_chunk))
                current_chunk = [sentence]
                current_length = sent_len
            else:
                current_chunk.append(sentence)
                current_length += sent_len

        if current_chunk:
            chunks.append(" ".join(current_chunk))

        return chunks

```

### 4. State Transfer & Retry Mechanism

Lớp Persistence ghi lại trạng thái từng chunk vào file `state.json` (hoặc SQLite local) ngay sau khi xử lý. Nếu bị gián đoạn hoặc lỗi, lần chạy tiếp theo sẽ nạp lại state và chỉ chạy những chunk chưa `COMPLETED`.

```python
# infrastructure/persistence/json_state_repository.py
import json
from pathlib import Path

class JSONStateRepository:
    def __init__(self, state_file: Path = Path(".tts_state.json")):
        self.state_file = state_file

    def save_state(self, job_id: str, chunks: list[dict]):
        data = self._load_all()
        data[job_id] = chunks
        with open(self.state_file, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    def load_state(self, job_id: str) -> list[dict]:
        data = self._load_all()
        return data.get(job_id, [])

    def _load_all(self) -> dict:
        if not self.state_file.exists():
            return {}
        with open(self.state_file, "r", encoding="utf-8") as f:
            return json.load(f)

```

### 5. Strategy Pattern cho các TTS Providers

Tạo giao diện `BaseTTSProvider` chung cho các engine (System, Edge, Google Translate, Google Cloud API Key).

```python
# domain/services.py
from abc import ABC, abstractmethod
from domain.value_objects import VoiceConfig

class BaseTTSProvider(ABC):
    @abstractmethod
    async def synthesize(self, text: str, config: VoiceConfig, output_path: str) -> bool:
        pass

# infrastructure/tts_providers/edge_provider.py
import edge_tts
from domain.services import BaseTTSProvider
from domain.value_objects import VoiceConfig

class EdgeTTSProvider(BaseTTSProvider):
    async def synthesize(self, text: str, config: VoiceConfig, output_path: str) -> bool:
        # Chuyển đổi rate, pitch, volume sang định dạng edge-tts string (+10%, -5Hz...)
        rate_str = f"{int((config.rate - 1) * 100):+d}%"
        volume_str = f"{int((config.volume - 1) * 100):+d}%"
        pitch_str = f"{int(config.pitch):+d}Hz"

        communicate = edge_tts.Communicate(
            text=text,
            voice=config.voice_id,
            rate=rate_str,
            volume=volume_str,
            pitch=pitch_str
        )
        await communicate.save(output_path)
        return True

```

### 7. Quy trình xử lý lỗi & Hợp nhất File Audio

1. **State Transfer:** Mỗi file khi được quét sẽ tạo ra một `Job` và danh sách `Chunk` trong file state (`.tts_state.json`). Cập nhật `COMPLETED` hoặc `FAILED` ngay sau mỗi chunk. Khi người dùng chạy lại lệnh `--resume`, hệ thống sẽ bỏ qua các chunk đã `COMPLETED`.
2. **Audio Merging:** Dùng thư viện `pydub` (hoặc `ffmpeg` trực tiếp) để nối ghép các đoạn audio nhỏ theo đúng thứ tự `sequence_index` sau khi tất cả chunk trong một file hoàn thành.
