Kiến trúc **Clean Architecture** kết hợp với **DDD (Domain-Driven Design)** giúp tách biệt hoàn toàn giữa **Nghiệp vụ (Core Domain)**, **Luồng xử lý (Use Cases)** và **Chi tiết kỹ thuật (Crawler BeautifulSoup, SQLite3)**.

Dưới đây là bản phân tích chi tiết và mã nguồn hoàn chỉnh cho ứng dụng Crawler `truyenfull.live`.

---

## 1. Phân tích Kiến trúc DDD & Clean Architecture

```
                       ┌──────────────────────────────────────────┐
                       │           Presentation / CLI             │
                       └────────────────────┬─────────────────────┘
                                            │
                       ┌────────────────────▼─────────────────────┐
                       │         Application (Use Cases)          │
                       └──────────┬──────────────────────┬────────┘
                                  │                      │
       ┌──────────────────────────▼────────┐   ┌─────────▼────────────────────────┐
       │     Infrastructure (Persist/Web)  │   │          Domain (Core)           │
       │  (SQLite, BeautifulSoup, Requests)│───► (Entities, Aggregates, Repos)    │
       └───────────────────────────────────┘   └──────────────────────────────────┘

```

### Phân chia các Layer:

1. **Domain Layer (Core):**
* **Entities & Value Objects:** `Novel` (Aggregate Root), `Chapter`, `Author`, `Listing`.
* **Repository Interfaces:** Khai báo contract lưu trữ (`INovelRepository`) mà không quan tâm là SQLite hay MySQL.


2. **Application Layer (Use Cases):**
* Chứa các luồng công việc: `CrawlNovelUseCase`, `CrawlListingUseCase`.
* Khai báo interface cho Web Scraper (`IScraperService`).


3. **Infrastructure Layer:**
* **Scraper:** Cài đặt `BeautifulSoup4` + `httpx`/`requests` để cào dữ liệu từ HTML theo cấu trúc URL.
* **Persistence:** Cài đặt `SQLite3` để lưu trữ dữ liệu vào database.


4. **Presentation / Entry Point (`main.py`):**
* Khởi tạo Dependency Injection và chạy ứng dụng qua CLI.

### Layer 2: Application (`src/application/`)

#### `interfaces.py`

```python
from abc import ABC, abstractmethod
from typing import List, Tuple, Optional
from src.domain.entities import Novel, Chapter

class IScraperService(ABC):
    @abstractmethod
    def fetch_listing_novels(self, listing_slug: str, page: int) -> Tuple[List[str], bool]:
        """Trả về danh sách novel_slug và boolean has_next_page"""
        pass

    @abstractmethod
    def fetch_novel_info(self, novel_slug: str) -> Tuple[Novel, int]:
        """Trả về thông tin cơ bản của Novel và tổng số trang chapter list"""
        pass

    @abstractmethod
    def fetch_chapter_headers_from_page(self, novel_slug: str, page: int) -> List[Chapter]:
        """Lấy danh sách các chapter (tiêu đề, chapter_no, link) từ trang danh sách"""
        pass

    @abstractmethod
    def fetch_chapter_content(self, novel_slug: str, chapter_no: int) -> str:
        """Lấy nội dung văn bản chi tiết của chapter"""
        pass

```

#### `use_cases.py`

```python
import time
from src.domain.repositories import INovelRepository
from src.application.interfaces import IScraperService

class CrawlNovelUseCase:
    def __init__(self, scraper: IScraperService, repo: INovelRepository):
        self.scraper = scraper
        self.repo = repo

    def execute(self, novel_slug: str, fetch_content: bool = True):
        print(f"[+] Bắt đầu crawl truyện: {novel_slug}")
        
        # 1. Lấy thông tin novel & số trang danh sách chapter
        novel, total_chapter_pages = self.scraper.fetch_novel_info(novel_slug)
        self.repo.save_novel(novel)
        print(f"    -> Đã lưu thông tin truyện '{novel.title}' (Có {total_chapter_pages} trang chapter)")

        # 2. Duyệt từng trang danh sách chapter
        for page in range(1, total_chapter_pages + 1):
            chapters = self.scraper.fetch_chapter_headers_from_page(novel_slug, page)
            print(f"    -> Đang xử lý trang chapter {page}/{total_chapter_pages} ({len(chapters)} chuơng)")

            for ch in chapters:
                # Nếu đã có nội dung trong DB thì bỏ qua (Tránh crawl lại)
                if self.repo.chapter_exists(novel_slug, ch.chapter_no):
                    continue

                if fetch_content:
                    try:
                        ch.content = self.scraper.fetch_chapter_content(novel_slug, ch.chapter_no)
                        time.sleep(0.5) # Rate limiting
                    except Exception as e:
                        print(f"      [!] Lỗi cào chương {ch.chapter_no}: {e}")
                        ch.content = ""

                self.repo.save_chapter(ch)
                print(f"      - Saved Chapter {ch.chapter_no}: {ch.title}")

class CrawlListingUseCase:
    def __init__(self, scraper: IScraperService, novel_use_case: CrawlNovelUseCase):
        self.scraper = scraper
        self.novel_use_case = novel_use_case

    def execute(self, listing_slug: str, max_pages: int = 1):
        print(f"[===] Bắt đầu crawl Danh mục: {listing_slug} [===]")
        for page in range(1, max_pages + 1):
            print(f"\n--- Crawling Listing Page {page} ---")
            novel_slugs, has_next = self.scraper.fetch_listing_novels(listing_slug, page)
            
            for slug in novel_slugs:
                self.novel_use_case.execute(slug, fetch_content=True)

            if not has_next:
                break
```

```python
import sqlite3

def init_db(db_path: str = "crawler.db"):
    conn = sqlite3.connect(db_path)
    cursor = conn.cursor()
    
    # Table Novels
    cursor.execute("""
    CREATE TABLE IF NOT EXISTS novels (
        slug TEXT PRIMARY KEY,
        title TEXT NOT NULL,
        author TEXT,
        description TEXT,
        cover_url TEXT
    )
    """)
    
    # Table Chapters
    cursor.execute("""
    CREATE TABLE IF NOT EXISTS chapters (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        novel_slug TEXT NOT NULL,
        chapter_no INTEGER NOT NULL,
        title TEXT,
        content TEXT,
        FOREIGN KEY (novel_slug) REFERENCES novels (slug),
        UNIQUE(novel_slug, chapter_no)
    )
    """)
    
    conn.commit()
    conn.close()
```

**`sqlite_repo.py`**

```python
import sqlite3
from typing import Optional
from src.domain.entities import Novel, Chapter
from src.domain.repositories import INovelRepository

class SQLiteNovelRepository(INovelRepository):
    def __init__(self, db_path: str = "crawler.db"):
        self.db_path = db_path

    def _get_connection(self):
        return sqlite3.connect(self.db_path)

    def save_novel(self, novel: Novel) -> None:
        with self._get_connection() as conn:
            cursor = conn.cursor()
            cursor.execute("""
                INSERT INTO novels (slug, title, author, description, cover_url)
                VALUES (?, ?, ?, ?, ?)
                ON CONFLICT(slug) DO UPDATE SET
                    title=excluded.title,
                    author=excluded.author,
                    description=excluded.description,
                    cover_url=excluded.cover_url
            """, (novel.slug, novel.title, novel.author, novel.description, novel.cover_url))

    def save_chapter(self, chapter: Chapter) -> None:
        with self._get_connection() as conn:
            cursor = conn.cursor()
            cursor.execute("""
                INSERT INTO chapters (novel_slug, chapter_no, title, content)
                VALUES (?, ?, ?, ?)
                ON CONFLICT(novel_slug, chapter_no) DO UPDATE SET
                    title=excluded.title,
                    content=excluded.content
            """, (chapter.novel_slug, chapter.chapter_no, chapter.title, chapter.content))

    def get_novel(self, slug: str) -> Optional[Novel]:
        with self._get_connection() as conn:
            cursor = conn.cursor()
            cursor.execute("SELECT slug, title, author, description, cover_url FROM novels WHERE slug=?", (slug,))
            row = cursor.fetchone()
            if row:
                return Novel(slug=row[0], title=row[1], author=row[2], description=row[3], cover_url=row[4])
        return None

    def chapter_exists(self, novel_slug: str, chapter_no: int) -> bool:
        with self._get_connection() as conn:
            cursor = conn.cursor()
            cursor.execute(
                "SELECT 1 FROM chapters WHERE novel_slug=? AND chapter_no=? AND content IS NOT NULL AND content != ''", 
                (novel_slug, chapter_no)
            )
            return cursor.fetchone() is not None

```

#### Scraper (`src/infrastructure/scraper/truyenfull.py`)

```python
import re
import requests
from bs4 import BeautifulSoup
from typing import List, Tuple
from src.domain.entities import Novel, Chapter
from src.application.interfaces import IScraperService

class TruyenFullScraper(IScraperService):
    BASE_URL = "https://truyenfull.live"

    def __init__(self):
        self.headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"
        }

    def _get_soup(self, url: str) -> BeautifulSoup:
        res = requests.get(url, headers=self.headers, timeout=10)
        res.raise_for_status()
        return BeautifulSoup(res.text, "html.parser")

    def fetch_listing_novels(self, listing_slug: str, page: int) -> Tuple[List[str], bool]:
        # URL pattern: site/listing-slug/ hoặc site/listing-slug/trang-2/
        url = f"{self.BASE_URL}/{listing_slug}/" if page == 1 else f"{self.BASE_URL}/{listing_slug}/trang-{page}/"
        soup = self._get_soup(url)
        
        slugs = []
        # Tùy biến CSS selector dựa theo HTML thực tế của TruyenFull
        elements = soup.select(".list-truyen .truyen-title a, .list-page .truyen-title a")
        for a in elements:
            href = a.get("href", "").strip("/")
            slug = href.split("/")[-1]
            if slug and slug not in slugs:
                slugs.append(slug)

        # Kiểm tra trang tiếp theo
        has_next = bool(soup.select(".pagination .next, a[rel='next']"))
        return slugs, has_next

    def fetch_novel_info(self, novel_slug: str) -> Tuple[Novel, int]:
        url = f"{self.BASE_URL}/{novel_slug}/"
        soup = self._get_soup(url)

        title = soup.select_one("h3.title, .info-holder .title").get_text(strip=True) if soup.select_one("h3.title, .info-holder .title") else novel_slug
        
        # Author
        author_elem = soup.select_one("a[itemprop='author'], .info a[href*='/tac-gia/']")
        author = author_elem.get_text(strip=True) if author_elem else "Unknown"

        # Description
        desc_elem = soup.select_one(".desc-text, div[itemprop='description']")
        description = desc_elem.get_text("\n", strip=True) if desc_elem else ""

        # Cover image
        cover_elem = soup.select_one(".books .book img, .info-holder img")
        cover_url = cover_elem.get("src", "") if cover_elem else ""

        # Parse tổng số trang chapter list (phân trang trong chi tiết truyện)
        total_pages = 1
        pagination = soup.select(".pagination page-nav, .pagination a")
        pages = []
        for p in pagination:
            text = p.get_text(strip=True)
            if text.isdigit():
                pages.append(int(text))
        if pages:
            total_pages = max(pages)

        novel = Novel(
            slug=novel_slug,
            title=title,
            author=author,
            description=description,
            cover_url=cover_url,
            total_pages=total_pages
        )
        return novel, total_pages

    def fetch_chapter_headers_from_page(self, novel_slug: str, page: int) -> List[Chapter]:
        url = f"{self.BASE_URL}/{novel_slug}/" if page == 1 else f"{self.BASE_URL}/{novel_slug}/trang-{page}/"
        soup = self._get_soup(url)

        chapters = []
        links = soup.select("ul.list-chapter a, #list-chapter a")
        
        for a in links:
            ch_title = a.get_text(strip=True)
            href = a.get("href", "")
            
            # Extract chapter_no từ URL dạng: /novel-slug/chuong-196/
            match = re.search(r'chuong-(\d+)', href)
            if match:
                ch_no = int(match.group(1))
                chapters.append(Chapter(
                    novel_slug=novel_slug,
                    chapter_no=ch_no,
                    title=ch_title,
                    url=href
                ))
        return chapters

    def fetch_chapter_content(self, novel_slug: str, chapter_no: int) -> str:
        url = f"{self.BASE_URL}/{novel_slug}/chuong-{chapter_no}/"
        soup = self._get_soup(url)

        content_elem = soup.select_one("#chapter-c, .chapter-c, .chapter-content")
        if not content_elem:
            return ""

        # Remove ads or unwanted tags inside content
        for unwanted in content_elem.select("script, ins, .ads"):
            unwanted.decompose()

        return content_elem.get_text("\n\n", strip=True)

```

### Layer 4: Presentation / Main Entry (`main.py`)

```python
import sys
from src.infrastructure.persistence.database import init_db
from src.infrastructure.persistence.sqlite_repo import SQLiteNovelRepository
from src.infrastructure.scraper.truyenfull import TruyenFullScraper
from src.application.use_cases import CrawlNovelUseCase, CrawlListingUseCase

def main():
    # 1. Khởi tạo Database
    DB_FILE = "crawler.db"
    init_db(DB_FILE)

    # 2. Khởi tạo Infrastructure Dependencies (Adapters)
    repo = SQLiteNovelRepository(DB_FILE)
    scraper = TruyenFullScraper()

    # 3. Khởi tạo Application Use Cases
    novel_use_case = CrawlNovelUseCase(scraper=scraper, repo=repo)
    listing_use_case = CrawlListingUseCase(scraper=scraper, novel_use_case=novel_use_case)

    # 4. Điều hướng ứng dụng
    print("=== TRUYENFULL CRAWLER (CLEAN ARCH + DDD) ===")
    print("1. Crawl một truyện theo slug")
    print("2. Crawl danh mục truyện (Listing)")
    
    choice = input("Chọn chức năng (1/2): ").strip()

    if choice == "1":
        slug = input("Nhập novel slug (VD: nhat-ky-nuoi-con-bang-my-thuc): ").strip()
        if slug:
            novel_use_case.execute(novel_slug=slug, fetch_content=True)
    elif choice == "2":
        listing_slug = input("Nhập listing slug (VD: danh-sach/truyen-full): ").strip()
        max_pages = int(input("Số trang listing cần cào: ") or 1)
        listing_use_case.execute(listing_slug=listing_slug, max_pages=max_pages)
    else:
        print("Lựa chọn không hợp lệ!")

if __name__ == "__main__":
    main()

```

## 4. Ưu điểm của thiết kế này

1. **Khả năng mở rộng (Extensibility):**
* Nếu ngày mai trang `truyenfull.live` đổi layout hoặc đổi domain, bạn chỉ cần sửa duy nhất class `TruyenFullScraper` trong tầng **Infrastructure**. Tầng Domain và Business Logic giữ nguyên 100%.
* Nếu muốn chuyển từ **SQLite3** sang **PostgreSQL**, chỉ cần viết thêm một class `PostgresNovelRepository` implement interface `INovelRepository` và thay thế vào Dependency Injection trong `main.py`.


2. **Tuân thủ Nguyên lý SOLID:**
* **DIP (Dependency Inversion Principle):** Application Use Case phụ thuộc vào Abstraction (`IScraperService`, `INovelRepository`), không phụ thuộc trực tiếp vào BeautifulSoup hay SQLite3.


3. **Idempotent / Anti-Duplication:**
* SQLite Repository sử dụng `ON CONFLICT` và kiểm tra `chapter_exists()` giúp chương trình có thể dừng/chạy lại liên tục mà không lo mất dữ liệu hay ghi trùng dữ liệu cũ.
