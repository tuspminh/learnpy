### **1. Đặt bài toán Quan hệ Nhiều - Nhiều (N - N)**

Xét hệ thống bán hàng:

* Một **Đơn hàng** có thể chứa **nhiều Sản phẩm**.
* Một **Sản phẩm** có thể xuất hiện trong **nhiều Đơn hàng**.

Trong CSDL quan hệ, ta **không thể** nhét một danh sách sản phẩm vào 1 ô dữ liệu. Để giải quyết, ta cần dùng một **Bảng trung gian (Junction Table / Pivot Table)** chứa 2 khóa ngoại tham chiếu đến 2 bảng chính.

```
+------------+       +-------------------+       +-----------+
|  DonHang   | 1---N |  ChiTietDonHang   | N---1 |  SanPham  |
|------------|       |-------------------|       |-----------|
| id (PK)    |       | don_hang_id (FK)  |       | id (PK)   |
| ngay_dat   |       | san_pham_id (FK)  |       | ten_sp    |
+------------+       | so_luong, gia_ban |       +-----------+
                     +-------------------+

```

---

### **2. Thực hành Code Python: Khởi tạo Bảng Trung Gian**

Tạo file mới hoặc viết tiếp vào mô hình quản lý bán hàng:

```python
import sqlite3

conn = sqlite3.connect('cuahang_v2.db')
cursor = conn.cursor()
cursor.execute("PRAGMA foreign_keys = ON;")

# 1. Bảng SanPham
cursor.execute("""
CREATE TABLE IF NOT EXISTS SanPham (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    ten_sp TEXT NOT NULL,
    gia_niem_yet REAL NOT NULL
);
""")

# 2. Bảng trung gian ChiTietDonHang
# Kết hợp (don_hang_id, san_pham_id) làm Primary Key để 1 sản phẩm không bị trùng 2 lần trong 1 đơn
cursor.execute("""
CREATE TABLE IF NOT EXISTS ChiTietDonHang (
    don_hang_id INTEGER,
    san_pham_id INTEGER,
    so_luong INTEGER NOT NULL CHECK(so_luong > 0),
    gia_luc_ban REAL NOT NULL,
    PRIMARY KEY (don_hang_id, san_pham_id),
    FOREIGN KEY (don_hang_id) REFERENCES DonHang(id) ON DELETE CASCADE,
    FOREIGN KEY (san_pham_id) REFERENCES SanPham(id) ON DELETE RESTRICT
);
""")

conn.commit()
print("Đã tạo bảng trung gian ChiTietDonHang thành công!")

```

> **Lưu ý:** Lưu `gia_luc_ban` vào bảng trung gian là bắt buộc, vì giá sản phẩm sau này có thể tăng/giảm nhưng giá trên hóa đơn đã bán cho khách thì không được thay đổi!

### **3. Thêm dữ liệu & Truy vấn ghép 3 Bảng với `JOIN**`

Để lấy ra toàn bộ thông tin đơn hàng gồm: **Tên khách + Tên sản phẩm + Số lượng + Thành tiền**, ta cần ghép cả 3-4 bảng lại với nhau bằng chuỗi `JOIN`.

```python
# Thêm dữ liệu mẫu sản phẩm
ds_sp = [("Laptop Dell", 15000000.0), ("Chuột Logi", 500000.0), ("Bàn phím", 1200000.0)]
cursor.executemany("INSERT INTO SanPham (ten_sp, gia_niem_yet) VALUES (?, ?)", ds_sp)

# Giả sử Đơn hàng ID = 1 mua: 1 Laptop + 2 Chuột Logi
chi_tiet_don_1 = [
    (1, 1, 1, 15000000.0), # (don_hang_id, san_pham_id, so_luong, gia_luc_ban)
    (1, 2, 2, 500000.0)
]
cursor.executemany("INSERT INTO ChiTietDonHang VALUES (?, ?, ?, ?)", chi_tiet_don_1)
conn.commit()

# --- TRUY VẤN GHÉP 4 BẢNG ---
sql_chi_tiet = """
SELECT 
    dh.id AS ma_don,
    kh.ho_ten AS ten_khach,
    sp.ten_sp,
    ct.so_luong,
    ct.gia_luc_ban,
    (ct.so_luong * ct.gia_luc_ban) AS thanh_tien
FROM DonHang dh
INNER JOIN KhachHang kh ON dh.khach_hang_id = kh.id
INNER JOIN ChiTietDonHang ct ON dh.id = ct.don_hang_id
INNER JOIN SanPham sp ON ct.san_pham_id = sp.id
WHERE dh.id = ?;
"""

cursor.execute(sql_chi_tiet, (1,))
danh_sach_sp_trong_don = cursor.fetchall()

print("--- CHI TIẾT ĐƠN HÀNG #1 ---")
for row in danh_sach_sp_trong_don:
    print(f"Khách: {row[1]} | Mua: {row[2]} | SL: {row[3]} | Đơn giá: {row[4]:,.0f} | Thành tiền: {row[5]:,.0f} VNĐ")

conn.close()

```
