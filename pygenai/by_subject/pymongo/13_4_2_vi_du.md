## Giai đoạn 4 - Bài 2: Xây dựng REST API hoàn chỉnh với FastAPI, Beanie & MongoDB

Trong bài học cuối cùng này, chúng ta sẽ kết nối tất cả kiến thức đã học lại với nhau để xây dựng một dịch vụ **REST API hoàn chỉnh** cho quản lý nhân viên.

Ứng dụng sẽ sử dụng **FastAPI** (Web Framework tốc độ cao), **Beanie** (Async ODM) và **MongoDB**.

#### **Bước 2: `models.py` (Định nghĩa Document & Schemas)**

Ta định nghĩa Document Beanie lưu vào Database và các Schema Pydantic cho đầu vào/đầu ra của API.

```python
from beanie import Document
from pydantic import BaseModel, EmailStr, Field
from typing import List, Optional

# 1. Beanie Document (Lưu trữ trong MongoDB)
class NhanVien(Document):
    ten: str = Field(..., max_length=100)
    email: EmailStr
    tuoi: int = Field(..., ge=18, le=65)
    phong_ban: str = "IT"
    luong: float = Field(..., gt=0)
    kynang: List[str] = []

    class Settings:
        name = "nhan_vien"  # Tên collection

# 2. Pydantic Schema cho Request Update (Cho phép cập nhật từng trường)
class NhanVienUpdateSchema(BaseModel):
    ten: Optional[str] = None
    email: Optional[EmailStr] = None
    tuoi: Optional[int] = Field(None, ge=18, le=65)
    phong_ban: Optional[str] = None
    luong: Optional[float] = Field(None, gt=0)
    kynang: Optional[List[str]] = None

```

---

#### **Bước 3: `database.py` (Kết nối Database)**

Khởi tạo kết nối bất đồng bộ (Async) với MongoDB khi API khởi động.

```python
import os
from motor.motor_asyncio import AsyncIOMotorClient
from beanie import init_beanie
from dotenv import load_dotenv
from models import NhanVien

load_dotenv()

MONGO_URI = os.getenv("MONGO_URI", "mongodb://localhost:27017")
DB_NAME = os.getenv("DB_NAME", "hoc_python_db")

async def init_db():
    client = AsyncIOMotorClient(MONGO_URI)
    # Khởi tạo Beanie với database và danh sách Document Models
    await init_beanie(
        database=client[DB_NAME],
        document_models=[NhanVien]
    )
    print("✅ Đã kết nối thành công tới MongoDB qua Beanie!")

```

#### **Bước 4: `main.py` (Xây dựng REST API Endpoints)**

Viết các API Endpoints hỗ trợ đầy đủ thao tác CRUD:

```python
from fastapi import FastAPI, HTTPException, status
from contextlib import asynccontextmanager
from typing import List
from beanie import PydanticObjectId

from database import init_db
from models import NhanVien, NhanVienUpdateSchema

# 1. Quản lý vòng đời ứng dụng (Lifespan)
@asynccontextmanager
async def lifespan(app: FastAPI):
    await init_db()  # Khởi tạo kết nối DB khi Server bật
    yield

app = FastAPI(title="Employee Management API", lifespan=lifespan)

# --- 2. REST API ENDPOINTS ---

# 📌 CREATE: Tạo nhân viên mới
@app.post("/api/nhan-vien", response_model=NhanVien, status_code=status.HTTP_201_CREATED)
async def create_employee(nv: NhanVien):
    # Kiểm tra trùng lặp email
    existing_nv = await NhanVien.find_one(NhanVien.email == nv.email)
    if existing_nv:
        raise HTTPException(
            status_code=400, 
            detail="Email này đã tồn tại trong hệ thống."
        )
    await nv.insert()
    return nv

# 📌 READ ALL: Lấy danh sách nhân viên (Có lọc theo phòng ban)
@app.get("/api/nhan-vien", response_model=List[NhanVien])
async def get_all_employees(phong_ban: str = None, limit: int = 10, skip: int = 0):
    query = NhanVien.find_all()
    if phong_ban:
        query = NhanVien.find(NhanVien.phong_ban == phong_ban)
    
    return await query.skip(skip).limit(limit).to_list()

# 📌 READ ONE: Lấy chi tiết 1 nhân viên theo ID
@app.get("/api/nhan-vien/{employee_id}", response_model=NhanVien)
async def get_employee_by_id(employee_id: PydanticObjectId):
    nv = await NhanVien.get(employee_id)
    if not nv:
        raise HTTPException(status_code=404, detail="Không tìm thấy nhân viên.")
    return nv

# 📌 UPDATE: Cập nhật thông tin nhân viên
@app.put("/api/nhan-vien/{employee_id}", response_model=NhanVien)
async def update_employee(employee_id: PydanticObjectId, req_data: NhanVienUpdateSchema):
    nv = await NhanVien.get(employee_id)
    if not nv:
        raise HTTPException(status_code=404, detail="Không tìm thấy nhân viên.")
    
    # Chỉ lấy các trường được gửi lên (bỏ qua giá trị None)
    update_data = req_data.model_dump(exclude_unset=True)
    await nv.set(update_data)
    return nv

# 📌 DELETE: Xóa nhân viên
@app.delete("/api/nhan-vien/{employee_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_employee(employee_id: PydanticObjectId):
    nv = await NhanVien.get(employee_id)
    if not nv:
        raise HTTPException(status_code=404, detail="Không tìm thấy nhân viên.")
    await nv.delete()
    return None

```
