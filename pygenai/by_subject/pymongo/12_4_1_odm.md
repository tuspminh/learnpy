## Giai đoạn 4 - Bài 1: Quản lý Schema với ODM MongoEngine & Beanie trong Python

Ở các giai đoạn trước, chúng ta đã thao tác với MongoDB thông qua thư viện `pymongo` bằng cách xử lý các dictionary thuần túy. Tuy nhiên, trong các ứng dụng thực tế lớn, việc sử dụng các dictionary không có khung chuẩn (Schema) dễ dẫn đến sai sót dữ liệu, thiếu kiểm tra kiểu dữ liệu (Validation) và khó quản lý mã nguồn.

Giải pháp là sử dụng **ODM (Object-Document Mapper)**. ODM giúp ánh xạ các Document trong MongoDB thành các Lớp (Class) trong Python.

---

### 1. Tổng quan: ODM là gì & So sánh MongoEngine vs Beanie

| Đặc tính | **MongoEngine** | **Beanie** |
| --- | --- | --- |
| **Kiểu lập trình** | Đồng bộ (Synchronous) | Bất đồng bộ (Asynchronous / `asyncio`) |
| **Cơ sở nền tảng** | `pymongo` | `Motor` + `Pydantic` |
| **Phù hợp với** | Flask, Django, Scripts truyền thống | FastAPI, Tornado, Ứng dụng Async hiện đại |
| **Validation** | Sử dụng Field tích hợp của MongoEngine | Sử dụng Pydantic mạnh mẽ |

### 2. Phần 1: MongoEngine (Lập trình Đồng bộ - Sync)

#### **2.1. Cài đặt MongoEngine**

```bash
pip install mongoengine

```

#### **2.2. Khai báo Document Class & Kết nối**

```python
from mongoengine import connect, Document, StringField, IntField, ListField, EmailField

# 1. Kết nối tới MongoDB
connect(db="hoc_python_db", host="mongodb://localhost:27017")

# 2. Định nghĩa Schema bằng Python Class
class NhanVien(Document):
    meta = {'collection': 'nhan_vien_odm'}  # Tên collection trong DB
    
    ten = StringField(required=True, max_length=100)
    email = EmailField(required=True, unique=True)
    tuoi = IntField(min_value=18, max_value=65)
    phong_ban = StringField(default="IT")
    kynang = ListField(StringField())

# 3. Thao tác CRUD bằng MongoEngine
# --- CREATE ---
nv1 = NhanVien(
    ten="Nguyễn Văn A",
    email="nguyenvana@gmail.com",
    tuoi=28,
    phong_ban="IT",
    kynang=["Python", "MongoDB"]
)
nv1.save()  # Tự động validate và lưu vào MongoDB
print(f"✅ Đã tạo nhân viên với ID: {nv1.id}")

# --- READ ---
# Lọc danh sách nhân viên phòng IT có tuổi >= 25
ds_it = NhanVien.objects(phong_ban="IT", tuoi__gte=25)
for nv in ds_it:
    print(f"- {nv.ten} ({nv.email})")

# --- UPDATE ---
# Cập nhật phòng ban cho nv1
nv1.update(set__phong_ban="Marketing")

# --- DELETE ---
# nv1.delete()

```

### 3. Phần 2: Beanie (Lập trình Bất đồng bộ - Async với Pydantic)

Beanie hiện là lựa chọn ưu tiên hàng đầu khi xây dựng REST API bằng **FastAPI** nhờ hiệu năng Async vượt trội và tích hợp sâu với Pydantic.

#### **3.1. Cài đặt Beanie & Motor**

```bash
pip install beanie motor

```

#### **3.2. Thực hành với Beanie (Async)**

```python
import asyncio
from motor.motor_asyncio import AsyncIOMotorClient
from beanie import Document, init_beanie
from pydantic import Field, EmailStr
from typing import List, Optional

# 1. Khai báo Document bằng Beanie & Pydantic
class NhanVienAsync(Document):
    ten: str = Field(..., max_length=100)
    email: EmailStr
    tuoi: int = Field(..., ge=18, le=65)
    phong_ban: str = "IT"
    kynang: List[str] = []

    class Settings:
        name = "nhan_vien_beanie"  # Tên collection

async def main():
    # 2. Khởi tạo Motor Client & Beanie
    client = AsyncIOMotorClient("mongodb://localhost:27017")
    await init_beanie(database=client.hoc_python_db, document_models=[NhanVienAsync])

    # 3. Thao tác CRUD Async
    # --- CREATE ---
    nv = NhanVienAsync(
        ten="Trần Thị B",
        email="tranthib@gmail.com",
        tuoi=24,
        phong_ban="HR",
        kynang=["Tuyển dụng"]
    )
    await nv.insert()
    print(f"✅ [Async] Đã thêm nhân viên: {nv.ten}")

    # --- READ ---
    # Tìm 1 nhân viên theo email
    nv_found = await NhanVienAsync.find_one(NhanVienAsync.email == "tranthib@gmail.com")
    if nv_found:
        print(f"Tìm thấy: {nv_found.ten} - Phòng {nv_found.phong_ban}")

    # --- UPDATE ---
    if nv_found:
        nv_found.phong_ban = "IT"
        await nv_found.save()
        print("✅ Đã cập nhật phòng ban thành công!")

# Chạy vòng lặp sự kiện Async
if __name__ == "__main__":
    asyncio.run(main())

```

### 4. Ưu điểm khi dùng ODM

1. **Auto Validation:** Dữ liệu tự động được kiểm tra kiểu dữ liệu (đúng format Email, giới hạn giá trị tuổi, bắt buộc có tên,...) trước khi gửi tới MongoDB.
2. **Type Hinting & Auto-complete:** IDE (như VS Code, PyCharm) hiểu rõ các thuộc tính của đối tượng, hỗ trợ gợi ý code cực tốt.
3. **Mã nguồn sạch sẽ:** Không còn phải viết các chuỗi truy vấn hay dictionary lồng nhau phức tạp.
