Học MongoDB với Python là một kết hợp rất phổ biến trong phát triển web và xử lý dữ liệu. Để kết nối Python với MongoDB, thư viện tiêu chuẩn và phổ biến nhất được sử dụng là **PyMongo**.

Dưới đây là hướng dẫn từ cơ bản đến nâng cao từng bước.

---

### 1. Chuẩn bị môi trường

Trước tiên, bạn cần cài đặt thư viện **PyMongo** thông qua `pip`:

```bash
pip install pymongo

```

*Lưu ý: Bạn cần có sẵn một MongoDB server (cài cục bộ trên máy hoặc dùng dịch vụ đám mây MongoDB Atlas) để kết nối.*

---

### 2. Kết nối tới MongoDB

Để bắt đầu, nhập `MongoClient` từ thư viện `pymongo` và khởi tạo kết nối.

```python
from pymongo import MongoClient

# Kết nối tới MongoDB cục bộ (mặc định port 27017)
client = MongoClient("mongodb://localhost:27017/")

# Hoặc kết nối qua MongoDB Atlas (Thay <connection_string> bằng chuỗi kết nối của bạn)
# client = MongoClient("<connection_string>")

# Chọn/Tạo Database (Nếu chưa có, MongoDB sẽ tự tạo khi thêm dữ liệu)
db = client["hoc_python_db"]

# Chọn/Tạo Collection (Tương đương với Table trong SQL)
collection = db["nhan_vien"]

print("Kết nối thành công!")

```

---

### 3. Thao tác CRUD Cơ bản

CRUD đại diện cho 4 thao tác cơ bản: **C**reate (Thêm), **R**ead (Đọc), **U**pdate (Sửa), **D**elete (Xóa).

#### **C - Create (Thêm dữ liệu)**

Trong MongoDB, dữ liệu được lưu dưới dạng tài liệu (Document) tương tự như Python `dictionary`.

* **Thêm 1 tài liệu (`insert_one`):**

```python
nhan_vien_1 = {
    "ten": "Nguyễn Văn A",
    "tuoi": 25,
    "phong_ban": "IT",
    "kynang": ["Python", "MongoDB"]
}

result = collection.insert_one(nhan_vien_1)
print(f"Đã thêm 1 bản ghi với ID: {result.inserted_id}")

```

* **Thêm nhiều tài liệu (`insert_many`):**

```python
danh_sach_nv = [
    {"ten": "Trần Thị B", "tuoi": 30, "phong_ban": "HR", "kynang": ["Tuyển dụng"]},
    {"ten": "Lê Văn C", "tuoi": 22, "phong_ban": "IT", "kynang": ["Java", "SQL"]},
    {"ten": "Phạm Văn D", "tuoi": 28, "phong_ban": "Marketing", "kynang": ["SEO"]}
]

result = collection.insert_many(danh_sach_nv)
print(f"Đã thêm {len(result.inserted_ids)} bản ghi.")

```

---

#### **R - Read (Truy vấn dữ liệu)**

* **Tìm 1 tài liệu (`find_one`):**

```python
# Tìm nhân viên đầu tiên thuộc phòng IT
nv = collection.find_one({"phong_ban": "IT"})
print(nv)

```

* **Tìm tất cả/nhiều tài liệu (`find`):**

```python
# Tìm tất cả nhân viên có tuổi lớn hơn 23
query = {"tuoi": {"$gt": 23}}  # $gt là lớn hơn (greater than)
danh_sach = collection.find(query)

for item in danh_sach:
    print(f"- {item['ten']} | Tuổi: {item['tuoi']} | Phòng: {item['phong_ban']}")

```

---

#### **U - Update (Cập nhật dữ liệu)**

Để cập nhật dữ liệu, ta dùng các toán tử như `$set` (thay đổi giá trị), `$push` (thêm vào mảng), v.v.

* **Cập nhật 1 tài liệu (`update_one`):**

```python
# Đổi tuổi của 'Nguyễn Văn A' thành 26
dieu_kien = {"ten": "Nguyễn Văn A"}
gia_tri_moi = {"$set": {"tuoi": 26}}

collection.update_one(dieu_kien, gia_tri_moi)
print("Đã cập nhật tuổi của Nguyễn Văn A.")

```

* **Cập nhật nhiều tài liệu (`update_many`):**

```python
# Thêm một trường 'trang_thai': 'Đang làm việc' cho tất cả phòng IT
collection.update_many(
    {"phong_ban": "IT"},
    {"$set": {"trang_thai": "Đang làm việc"}}
)

```

---

#### **D - Delete (Xóa dữ liệu)**

* **Xóa 1 tài liệu (`delete_one`):**

```python
# Xóa nhân viên tên 'Phạm Văn D'
collection.delete_one({"ten": "Phạm Văn D"})
print("Đã xóa nhân viên.")

```

* **Xóa nhiều tài liệu (`delete_many`):**

```python
# Xóa tất cả nhân viên thuộc phòng 'HR'
collection.delete_many({"phong_ban": "HR"})

```
